# RH-SOL-02 shifted-lattice experiment

Primary object:

`C_n(delta) = sum_{k in Z^2} 1_{D_n}(k + delta)`, with `delta in [0,1)^2`.

Initial goals:

1. quantify invariance of the Dirichlet comb under lattice translation;
2. estimate translation-averaged count and variance;
3. test the Poisson-summation representation of the shifted count;
4. compare actual zeta loops with geometry-matched null curves.
