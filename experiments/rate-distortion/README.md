# RH-SOL-08 rate-distortion experiment

Study spectral recovery as information is removed by:

- increasing lattice spacing;
- random node subsampling;
- spatial coarse graining;
- reducing coordinate precision;
- replacing occupancy with lower-bit summaries.

Define task-specific distortion on a predeclared Dirichlet spectral vector and estimate an empirical information-vs-distortion curve.
