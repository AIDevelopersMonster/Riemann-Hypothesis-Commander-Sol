## Publication core

The package develops a controlled definability corridor for a multiplicative quotient that remembers only finite prime support and one square-defect bit. It preserves primality exactly while erasing prime coordinates, then tracks the return of finite phase, order, weak-monadic finite-set geometry, and finally coordinate arithmetic.

Core progression:

`exact primehood -> finite phase -> prime order -> cardinality synchronization -> full coordinate arithmetic`.

Key interaction theorem:

`order alone: decidable; EqCard alone: decidable; order + EqCard: arithmetic/undecidable`.
