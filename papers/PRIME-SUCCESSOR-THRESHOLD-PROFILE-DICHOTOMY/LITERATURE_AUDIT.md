# Literature Audit — Support-Cardinality Valuation Wall

**Date:** 2026-08-27

The targeted search focused on the conjunction of Ramanujan tau values at primes, variable valuation thresholds, first-order definability/model theory, finite graph coding, adelic Galois independence, and a finite-versus-infinite support transition.

## Closest structural sources

- David Loeffler, *Images of adelic Galois representations for modular forms*, Glasgow Mathematical Journal 59 (2017), 11-25, DOI `10.1017/S0017089516000367`, arXiv:1411.1789. This is the decisive adelic open-image input used to obtain independent finite-level residual control outside finitely many places.
- Kenneth Ribet's classical work on l-adic representations attached to modular forms supplies foundational large-image results.
- Trakhtenbrot's theorem supplies the undecidability endpoint after uniform interpretation of all finite directed graphs.
- T. Karimov, J. Nieuwveld, and J. Ouaknine, *Rich sequences and decidability of logical theories* (submitted 2026), studies undecidability for a structure containing `n -> |tau(n)|` by a different richness/quasi-randomness mechanism. Its language, structure, and coding mechanism differ from the threshold-profile structure used here.

## Search outcome

No exact prior theorem was found matching the support-cardinality dichotomy

`|P_+(kappa)|<infinity` versus `|P_+(kappa)|=infinity`

with the corresponding split between parameter-free interdefinability with zero depth and infinite residual graph universality.

This is a targeted literature-audit observation, not a historical-priority claim.
