## Claims cleared for publication

The article may state, inside the declared explicit-base / fixed-finite-signature / ordinary-FO cost model:

1. Uniform canonical truncated addition requires `Omega(m)` charged added primitive support.
2. Differential Zeckendorf memory has exact event count `|U_m|+|D_m| = 2m-2-s_F(m-1) = Theta(m)`.
3. Full Zeckendorf digit incidence and Zeckendorf event history are uniformly FO-interdefinable.
4. The Zeckendorf event generator is prefix-consistent and provenance-safe, with `Theta(m)` final materialized support and `O(log m)` transient current-word workspace in the direct implementation.
5. Optimal generated base-sort exact-AL1 materialized support is `Theta(m)`.
6. Differential binary/BIT memory also has `Theta(m)` event support and remains AL2.
7. Equal linear materialized support therefore does not determine AL1 versus AL2.
8. For prefix-coherent families, `DCE + Add => not Mul`.
9. Zeckendorf events have DCE through a word-automatic coherent infinite structure; binary/BIT events do not have DCE.
10. DCE is preserved under coherently liftable fixed-dimensional FO interpretations, including definable quotients; therefore no such coherent interpretation maps the Zeckendorf event family to the binary/BIT event family.
