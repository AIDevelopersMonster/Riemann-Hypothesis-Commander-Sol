# Fiber-Transport Theorem for Anonymous Terminal Outputs

**Project:** FCOA Admissibility Geometry  
**Status:** post-G3 proof consolidation  
**Date:** 2026-08-27

## 1. Purpose

G3 separates domain geometry from value-fiber geometry. The natural abstract question is:

> Given a domain relation and an anonymous output coloring of that domain, which automorphisms of the domain survive after the values are restored?

The answer is controlled by the partition of the domain into equal-value fibers.

This note records the exact relative theorem used by G3. No novelty or priority claim is made for the general colored-structure principle.

## 2. Relative setup

Let \(B\) be a base structure with an active sort \(X\). Let

\[
D\subseteq X^2
\]

be an additional binary relation preserved by the candidate automorphisms. Let \(O\) be a new pure output sort, disjoint from \(X\), and let

\[
c:D\to O
\]

be surjective.

Interpret \(c\) as a partial-operation layer: for \((x,y)\in D\), the new cell has terminal output \(c(x,y)\), while outside \(D\) this layer is undefined. The elements of \(O\) have no further structure and are not active arguments of the new layer.

Write

\[
\Gamma=\operatorname{Aut}(B,D).
\]

Define an equivalence relation on the set of domain cells:

\[
p\equiv_c q
\iff
c(p)=c(q),
\qquad p,q\in D.
\]

Thus \(\equiv_c\) is exactly the partition of \(D\) into value fibers.

## 3. Fiber-Transport Theorem

### Theorem

Restriction to the base structure gives a canonical isomorphism

\[
\boxed{
\operatorname{Aut}(B,D,O;c)
\cong
\operatorname{Stab}_{\Gamma}(\equiv_c),
}
\]

where

\[
\operatorname{Stab}_{\Gamma}(\equiv_c)
=
\left\{
 g\in\Gamma:
 p\equiv_c q
 \iff
 gp\equiv_c gq
 \text{ for all }p,q\in D
\right\}.
\]

Here \(g(x,y)=(gx,gy)\).

### Proof

Let \((g,h)\) be an automorphism of the expanded two-sorted structure, with \(g\) acting on the base structure and \(h\) on \(O\). Since \(g\) preserves \(D\), for every \(p\in D\),

\[
h(c(p))=c(gp).
\]

Therefore if \(c(p)=c(q)\), then

\[
c(gp)=h(c(p))=h(c(q))=c(gq).
\]

Applying the inverse automorphism gives the converse implication, so \(g\) preserves the fiber equivalence \(\equiv_c\).

Conversely, suppose \(g\in\Gamma\) preserves \(\equiv_c\). Because \(c\) is surjective, define

\[
h(c(p)):=c(gp).
\]

This is well-defined: if \(c(p)=c(q)\), then \(p\equiv_c q\), hence \(gp\equiv_c gq\), so \(c(gp)=c(gq)\). The same argument for \(g^{-1}\) shows that \(h\) is bijective. By construction,

\[
h(c(p))=c(gp)
\]

for all \(p\in D\), so \((g,h)\) is an automorphism of the expanded structure.

Surjectivity of \(c\) makes \(h\) uniquely determined by \(g\). Hence restriction is a canonical group isomorphism. \(\square\)

## 4. Named-output corollary

If every element of \(O\) is fixed individually — for example because outputs are named constants or lie in separately fixed singleton sorts — then the surviving base automorphisms are exactly

\[
\boxed{
\{g\in\Gamma:c(gp)=c(p)\text{ for every }p\in D\}.
}
\]

Equivalently, every value fiber must be preserved setwise rather than merely permuted among equal-status fibers.

Thus anonymous outputs and named outputs impose different symmetry conditions.

## 5. Non-surjective caveat

If \(c:D\to O\) is not surjective, unused outputs are invisible to the operation layer. In a pure output sort they may be permuted independently.

Let

\[
O_0=O\setminus\operatorname{im}(c).
\]

Then the restriction map acquires a kernel containing

\[
\operatorname{Sym}(O_0).
\]

In the pure-sort case the automorphism group has the corresponding unused-output factor. This is the same structural issue that appears in empty-relation variants of Domain Compilation.

## 6. Relative version over an existing operation

The theorem is intended to be used **relative to a fixed backbone**.

If \(B\) already contains an operation such as M0, then \(\Gamma\) is not the full symmetric group on \(X\); it is the automorphism group of the already-existing structure together with the new-cell domain \(D\). The value-fiber layer can only reduce this group further.

Hence there is a canonical symmetry ladder

\[
\boxed{
\operatorname{Aut}(B)
\supseteq
\operatorname{Aut}(B,D)
\supseteq
\pi_X\operatorname{Aut}(B,D,O;c),
}
\]

where the last group is the fiber-partition stabilizer.

This cleanly separates:

1. symmetry removed by **definedness/domain geometry**;
2. symmetry removed only by **value-fiber geometry**.

## 7. Application to G3-C

In G3-C the generic new-cell domain is the undirected path adjacency relation. Relative to M0,

\[
\Gamma\cong C_2,
\]

generated by path reversal \(r\).

The value partition has two fibers:

\[
D_+=\{(P_i,P_{i+1}):2\le i<N\},
\]

\[
D_-=\{(P_{i+1},P_i):2\le i<N\}.
\]

Reversal exchanges these two fibers. Therefore it preserves the fiber equivalence \(\equiv_c\), even though it does not preserve either fiber individually.

Hence

\[
\boxed{
\operatorname{Aut}(\otimes_C)\cong C_2.
}
\]

The output action forced by reversal is

\[
\Omega_+\leftrightarrow\Omega_-.
\]

This explains the G3 output-swap obstruction without a path-specific argument.

## 8. Application to G3-A

The G3-A anchor adds

\[
P_1\otimes_A P_0=\Omega_+.
\]

The definedness reduct on the base sort has

\[
\operatorname{Aut}(D_A\upharpoonright X_N)
\cong C_2\times C_2,
\]

generated by generic path reversal and the boundary transposition \(P_0\leftrightarrow P_1\).

However, the full value-fiber partition is preserved by neither nontrivial generator:

- path reversal would have to exchange \(\Omega_+\) and \(\Omega_-\), but the fixed anchor cell lies only in the \(\Omega_+\)-fiber;
- the boundary transposition does not preserve the M0 value laws and anchor fiber structure of the full operation.

Therefore the fiber-partition stabilizer is trivial:

\[
\boxed{
\operatorname{Aut}(\otimes_A)=1.
}
\]

This is the exact sense in which G3-A carries structural memory in values beyond definedness.

## 9. Value-Rigidity Index

For a finite active sort, define the working invariant

\[
\boxed{
\operatorname{VRI}(\star)
=
\left[
\operatorname{Aut}(D_\star\upharpoonright X):
\pi_X\operatorname{Aut}(\star)
\right].
}
\]

This is the index of the full-operation carrier automorphisms inside the definedness automorphisms.

It measures how much additional rigidity is contributed by values after the operation domain has already been fixed.

For the audited G3 branches:

\[
\operatorname{VRI}(G3\text{-}S)=1,
\]

\[
\operatorname{VRI}(G3\text{-}C)=1,
\]

\[
\boxed{
\operatorname{VRI}(G3\text{-}A)=4.
}
\]

The name `Value-Rigidity Index` is working terminology only.

## 10. Consequence for the research programme

Domain Compilation showed that a relation can be absorbed into operation definedness. G3 and the Fiber-Transport Theorem show a second layer:

\[
\boxed{
\text{domain geometry}
\quad+
\text{fiber partition}
}
\]

are distinct symmetry carriers.

The next natural question is quantitative:

> Can a bounded anonymous output alphabet produce an unbounded Value-Rigidity Index while the underlying generic domain remains maximally symmetric?

That question motivates the next branch. It does not require adding arithmetic operations on external indices.
