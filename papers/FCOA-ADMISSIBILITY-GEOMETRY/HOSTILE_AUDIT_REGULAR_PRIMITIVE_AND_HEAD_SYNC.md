## 2. Finding A — the nonregularity claim is correct, but the stated homomorphism proof is not

Both notes use the restricted EqGap skeleton

\[
L=\{A a^{n-1}BCa^{n-1}D:n\ge1\}.
\]

The language is indeed nonregular.

However, the sentence saying that a plain homomorphism turns this into \(\{u^nv^n\}\) is not justified when the two variable blocks use the same symbol and are distinguished only by position relative to the fixed middle markers. A homomorphism acts letterwise and cannot by itself relabel the left block and right block differently.

### Repair

Use the pumping lemma directly.

Assume \(L\) regular and let \(p\) be a pumping length. Take

\[
w=Aa^pBCa^pD.
\]

Any decomposition \(w=xyz\) with \(|xy|\le p+1\) and \(|y|>0\) that is pumpable within the first variable block changes only the first \(a\)-block while the second remains of length \(p\). Pumping therefore produces a word outside \(L\). Fixed endpoint conventions can be absorbed by increasing \(p\) by a constant.

Hence \(L\) is nonregular.

**Verdict:** theorem survives; proof text must be corrected.

## 3. Finding B — “two heads” alone do not cross the FO leakage wall

The local product-successor relation

\[
E(a,c;b,d)\iff Succ(a,b)\land Succ(c,d)
\]

is itself first-order definable from linear order. Therefore adding the local step as a static primitive does not increase FO expressive power beyond the ordered base structure.

What reaches EqGap is its unbounded reflexive-transitive closure:

\[
TC(E)((a,c),(b,d))
\iff
EqGap(a,b;c,d).
\]

Thus the correct threshold is not “two local operation symbols” or “two heads” in static FO. It is:

\[
\boxed{
\text{dimension-two synchronized product geometry}
+
\text{unbounded traversal closure}.
}
\]

This repairs the apparent tension with the Regular-Primitive Barrier.

## 4. Clean dimension-two closure threshold

Let \(S\) be successor on a finite chain.

For one dimension,

\[
TC(S)(a,b)\iff a\le b,
\]

which is already first-order definable in the ordered structure.

For the synchronous square,

\[
E((a,c),(b,d)):=S(a,b)\land S(c,d).
\]

Then

\[
TC(E)((a,c),(b,d))
\iff EqGap(a,b;c,d).
\]

Therefore:

\[
\boxed{
TC(S)\in AL0,
\qquad
TC(S\times S)=EqGap\in AL1.
}
\]

This is stronger and cleaner than the earlier head-count slogan.

## 5. Finding C — Cartesian-product sort requires a separate argument

The fixed finite-copy theorem does not literally cover a quadratic configuration sort \(G_m^2\). Therefore the old text should not imply that Theorem 6.1 directly handles such a sort.

But the intended negative conclusion is still rigorous.

If \(C_m=G_m^2\) is introduced as a genuine Cartesian-product sort with only projections, equality, order-definable coordinate relations, and local product successor, then this is a fixed-dimensional FO interpretation in the base linear order.

Every FO formula over the interpreted pair structure translates back to an FO formula over the base order. Since EqGap is not FO-definable in finite linear order, the pair sort plus local step still cannot define reachability/EqGap.

**Verdict:** conclusion survives; scope argument must be rewritten as an FO-interpretation argument rather than as an application of the finite-copy theorem.

## 6. Finding D — stopping condition does not smuggle in EqGap

The operational two-head machine uses only:

- successor;
- equality to the two designated targets;
- synchronous movement;
- unbounded iteration until one or both targets are reached/passed.

The equality test is local. The non-FO resource is the unbounded number of iterations. Thus EqGap is not hidden in the stopping predicate; it is generated by closure depth.

## 7. Finding E — graph-prefix consistency is sound

For generated truncated addition,

\[
Graph(\triangleplus_m)
=
Graph(\triangleplus_\infty)\cap G_m^3.
\]

An old triple never changes truth value under extension. Only the existential domain projection can grow when a previously absent result point enters the larger carrier.

No size-oracle defect is found here.

## 8. Finding F — fixed-depth nesting remains below the barrier

Any fixed-depth composition of position-regular primitive graphs remains FO-definable from a finite position-regular signature and is therefore position-regular.

Hence:

\[
\boxed{
\text{fixed syntactic nesting depth cannot cross the Regular-Primitive Barrier.}
}
\]

To reach EqGap by nesting, one must either:

1. let nesting depth grow with the input/carrier and materialize the resulting closure; or
2. insert a non-position-regular primitive/incidence relation.

This is an immediate corollary of the barrier and should be recorded as part of the central line.

## 9. Final hostile verdict

No counterexample to the Regular-Primitive Barrier was found.

After the two textual repairs above, the central results are supportable as:

\[
\boxed{
\mathbf F:\ \text{finite-copy position-regular primitive expansions cannot FO-define EqGap/Add.}
}
\]

and

\[
\boxed{
\mathbf F:\ TC(S)\in AL0\text{ while }TC(S\times S)=EqGap\in AL1.
