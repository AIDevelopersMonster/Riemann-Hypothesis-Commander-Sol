## 4. SOL-HYBRID — Joint Memory of Partial Operations

**Verdict:** `NOT YET PUBLICATION READY AS A SINGLE BRANCH PAPER`.

There are two strong but currently mixed strands.

### Strand A — finite joint fiber synchronization

The branch has a genuine shared-output lift-compatibility mechanism and sharp small witnesses. However the branch contains a stale upstream memo that still states the old active-carrier minimum `n=3`, whereas the director repair established a two-point shared-output JFS witness with four cells and the Pareto frontier

`(n,cells)=(2,4)` and `(3,3)`.

The publication version must therefore synchronize all theorem ledgers, replace misleading canonical `oplus/otimes` notation by abstract sandbox symbols, and state explicitly that common-output JFS uses an ambient-signature extension rather than the exact canonical M0 output architecture.

### Strand B — CRT arithmetic-memory compression

The branch has explicit linear-record constructions for AL1 and AL2 using size-dependent auxiliary residue carriers. These are important and do not contradict the main Presburger Compression Barrier because they are varied/auxiliary-sort presentations.

Before publication they need a dedicated hostile audit of:

- provenance/cost of choosing size-dependent moduli;
- total auxiliary-carrier cost, not only table-record count;
- the fixed two-operation incidence compilation and whether it preserves the claimed asymptotics without hidden role inflation;
- the lower-bound model used to claim exact `Theta(N)` rather than only `O(N)`.

Recommendation: split Hybrid into two possible papers rather than force one manuscript: **Joint Fiber Synchronization** and **CRT Arithmetic Memory / Resolution-Transport profiles**.
