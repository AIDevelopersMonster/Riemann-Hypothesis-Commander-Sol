# Interactive demonstration

RH-SOL-01 was released with a standalone HTML demonstration:

`Zeta_Argand_Lattice_Interactive_Demo_v0.1.1.html`

The demo requires no server and no external JavaScript libraries. It exposes the sampling/Nyquist relations used in the paper and allows interactive variation of `T` and `m`, including:

- `omega = log(m)`;
- local sampling frequency;
- local Nyquist frequency;
- reciprocal first-fold label `m* = T/(2*pi*m)`;
- fixed-point scale `sqrt(T/(2*pi))`;
- normalized variable `xi = T/(2*pi*m^2)`.

Canonical copy: the Zenodo record associated with DOI `10.5281/zenodo.22060296`.

SHA-256 of the v0.1.1 standalone HTML retained with the publication package:

`40769ac18e390769acfaa649b7abc3daa5d2ee449970ff23a967f8cb5f153c43`

The GitHub repository does not treat the demo as independent evidence; it is a visualization/inspection aid for the published formulas and selected empirical results.
