# HATTER-SOL-12 · RESEARCH KERNEL

## 0. Scope

This note fixes the broad mathematical object before selecting a narrow theorem spine.

The basic data are

\[
(n,W,C,O),
\]

where `n` is an integer, `W` an arithmetic world, `C` a carrier/geometry class, and `O` an observer.

For each triple `(n,W,C)` let

\[
\mathsf S(n;W,C)
\]

be the set of admissible structural states. An observer is a map

\[
O:\mathsf S(n;W,C)\to Y_O.
\]

The theory studies how fibers change when `W`, `C`, `O`, or scale changes.

---

## 1. Observer order

Let `O_1:S->Y_1` and `O_2:S->Y_2` be observers on the same state set.

Say that `O_2` is **coarser** than `O_1`, written

\[
O_1\succeq O_2,
\]

if there exists a map `f:Y_1->Y_2` such that

\[
O_2=f\circ O_1.
\]

### Theorem O12.1 — observer coarsening law

If `O_1\succeq O_2`, then for every `s in S`,

\[
\boxed{
O_1^{-1}(O_1(s))\subseteq O_2^{-1}(O_2(s)).
}
\]

Hence a coarser observer cannot decrease hidden structural multiplicity.

If the fibers are finite,

\[
\boxed{
\log_2|O_1^{-1}(O_1(s))|
\le
\log_2|O_2^{-1}(O_2(s))|.
}
\]

Proof: if `O_1(t)=O_1(s)`, then applying `f` gives `O_2(t)=O_2(s)`. QED.

This theorem is elementary but foundational: it turns "observer resolution" into a partial-order statement independent of any particular HATTER model.

## 2. Joint observers

For observers `O_1:S->Y_1` and `O_2:S->Y_2`, define

\[
O_1\vee O_2:S\to Y_1\times Y_2,
\qquad
(O_1\vee O_2)(s)=(O_1(s),O_2(s)).
\]

### Theorem O12.2 — joint-refinement law

\[
\boxed{
(O_1\vee O_2)^{-1}(y_1,y_2)
=O_1^{-1}(y_1)\cap O_2^{-1}(y_2).
}
\]

Therefore adding an independent observation can only split existing fibers, never merge previously separated states.

This is the abstract form of combining scalar, typed, orbital, polynomial, topology and geometry observations.

## 3. Carrier restriction

Suppose two carriers satisfy an admissibility inclusion

\[
\mathsf S(n;W,C_1)\subseteq\mathsf S(n;W,C_2).
\]

This occurs, for example, when `C_1` is a stricter architecture class than `C_2` and the state semantics are otherwise fixed.

### Theorem C12.1 — carrier restriction law

For any observer `O` defined on the larger state set and any value `y`,

\[
\boxed{
\mathcal F_O(n;W,C_1;y)
\subseteq
\mathcal F_O(n;W,C_2;y).
}
\]

Carrier restriction can therefore remove hidden states. It need not refine the observed value itself; it changes the admissible preimage.

This distinguishes **observer forgetting** from **carrier exclusion**.

## 4. World transport

A world transition `T:W->W'` is not assumed to preserve structural state. It induces a comparison problem

\[
\mathsf S(n;W,C)
\quad\leftrightarrow\quad
\mathsf S(n;W',C).
\]

When a canonical transport map

\[
\Phi_T:\mathsf S(n;W,C)\to\mathsf S(n;W',C)
\]

exists, one may ask whether observation commutes with world transport:

\[
O_{W'}\circ\Phi_T
\stackrel{?}{=}
\Psi_T\circ O_W.
\]

Failure is a **world-observer defect**.

For polynomial responses in the established prime-toggle world graph, the first exact defect is simply

\[
\nabla_qZ_n(R)=Z_R(n)-Z_{T_qR}(n).
\]

Higher mixed defects are the world digits from `WORLD_DIGIT_FIELD.md`.

## 5. Observation horizons

An infinite response field needs finite canonical truncations.

Let `I` be an ordered/addressed family of coordinates and `H` a finite down-set or cutoff. Define the truncated observer

\[
O_H=\pi_H\circ O_\infty,
\]

where `\pi_H` retains only coordinates in `H`.

If `H_1\subseteq H_2`, then

\[
O_{H_2}\succeq O_{H_1}.
\]

Hence by Theorem O12.1,

\[
\boxed{
\mathcal F_{O_{H_2}}(s)
\subseteq
\mathcal F_{O_{H_1}}(s).
}
\]

This gives a general monotone law for restricted orbits, restricted digits, bounded polynomial degree, bounded host scale, or bounded world radius.

The research problem is to choose horizons canonically from `n`, `W`, or the world graph rather than by arbitrary external enumeration.

## 6. World-digit hierarchy

For a prime-toggle cube generated by `Q`, the full response is

\[
A\mapsto Z_{T_A R_0}(n;X,Y).
\]

The mixed derivative family

\[
D_B=\left[\prod_{q\in B}(I-T_q)Z_n\right](R_0)
\]

is an exactly equivalent coordinate system on every finite cube.

A digit-order cutoff

\[
|B|\le r
\]

is therefore a canonical observer horizon measuring world interactions only up to order `r`.

This yields the nested observers

\[
O^{(0)}\preceq O^{(1)}\preceq O^{(2)}\preceq\cdots,
\]

where `O^(r)` retains all mixed world digits of order at most `r`.

A central question is whether the inclusions of corresponding fibers are strict for natural integer/world families.

## 7. Polynomial-coordinate horizons

For

\[
Z_W(n;X,Y)=\sum c_{a,b}X^aY^b,
\]

one may define canonical coefficient windows, for example

\[
a+b\le L,
\]

or retain only extremal coefficients, support rank, total-boundary slices, or anisotropy bands.

These are observers of the polynomial response, not new arithmetic invariants by definition.

The strongest version of the user's proposal is to make `L` a function of the number itself, such as a canonical factor-derived scale, thereby producing a **self-bounded observer**.

No particular factor cutoff is declared canonical yet; competing choices must be audited for invariance and usefulness.

## 8. Carrier memory beyond planar classes

For a surface carrier `C`, structural state may include more than local typed degrees.

Potential layers, to be kept distinct:

1. combinatorial embedding / rotation-system data;
2. homology or fundamental-group class of network cycles;
3. typed holonomy/monodromy when a natural label group exists;
4. embedding-dependent geometric sectors such as curvature sign.

The topological and geometric layers must not be conflated. In particular, curvature sign on an embedded torus is not a topological invariant.

A future torus theorem should prove a separation of the form

\[
\text{same coarse network response}
\quad\text{but}\quad
\text{different topological/geometric carrier state}.
\]

## 9. Structural memory profile

For finite fibers define

\[
M_O(n;W,C;s)=\log_2|O^{-1}(O(s))|.
\]

Rather than one scalar, HATTER-SOL-12 should study the **memory profile** along an observer chain

\[
O_0\preceq O_1\preceq\cdots\preceq O_r:
\]

\[
\boxed{
M_{O_0}\ge M_{O_1}\ge\cdots\ge M_{O_r}.
}
\]

Strict drops are observable resolution events.

HATTER-SOL-11's `3->2->1` law is the finite-cardinality prototype of such a profile.

---

## 10. Infinite readout versus infinite information

An infinite coordinate family may give an infinite response sequence while still being generated by finite data.

Therefore distinguish:

- coordinate length;
- number of distinct response states;
- rank/nonredundancy of coordinates;
- algorithmic description length;
- payload capacity.

Only the first is automatic from infinitely many worlds. Unbounded structural diversity or nonredundant rank requires theorem-level proof.

This distinction is mandatory before HATTER-SOL-13 applications.

## 11. Main theorem-building targets

1. Construct an explicit observer ladder for one integer where every stage strictly refines the previous one.
2. Prove a strict world-digit order hierarchy for a natural finite cube, if such an example exists.
3. Define and compare at least two self-bounded observer horizons derived canonically from `n`.
4. Produce a carrier separation theorem beyond planar geometry.
5. Determine whether fixed-number world-response diversity can be unbounded in a natural infinite family of worlds.
6. Identify a genuinely arithmetic label group/groupoid, if one exists, before introducing holonomy as a central invariant.
7. Audit all claims against factorization theory, graph coverings/gain graphs, representation varieties, symbolic dynamics/coding and sheaf-based consistency frameworks.
