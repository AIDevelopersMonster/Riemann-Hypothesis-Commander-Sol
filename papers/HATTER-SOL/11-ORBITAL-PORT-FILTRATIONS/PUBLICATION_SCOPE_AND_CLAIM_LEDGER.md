# HATTER-SOL-11 · Publication Scope and Claim Ledger

**Status:** mandatory pre-manuscript control document.

This ledger separates the exact proved statements from tempting stronger formulations. It is designed to prevent scope drift while consolidating many research notes into one publication.

---

## 1. Objects and forgetting maps

### Claim C1 — intrinsic orbital datum exists in the stated generic setting

**Allowed claim.** In the generic imaginary-quadratic setting treated by the branch, the natural symmetry action produces an intrinsic axial/oblique direction-orbit datum `Omega`, with Gaussian and Eisenstein fusion exceptions explicitly classified.

**Do not claim.** A universal ordered hierarchy of port strengths.

**Reason.** The strongest-first/sequential-activation hypothesis is explicitly falsified.

### Claim C2 — exact folded-fiber classification

**Allowed claim.** For generic odd interior folded pairs `P>Q>0`, the forgetting map from orbital data to the folded pair has exactly three canonical members.

**Do not claim.** Every algebraic quadratic order, arbitrary number field, or arbitrary interface model has the same three-element fiber.

### Claim C3 — `Xi` is a quotient, not the full orbital object

**Allowed claim.** The orbit-total state

`Xi=(A,O)=(a,b+c)`

is a canonical two-channel projection used for the exact network theorems in the main spine.

**Do not claim.** `Xi` retains all information present in `Omega=(a;{b,c})`.

## 2. Network-response claims

### Claim N1 — orbital information can be operationally visible

**Allowed claim.** Distinct members of one folded `(P,Q)` fiber can have different exact `Xi` network responses.

**Do not claim.** Every distinct `Omega` state is distinguishable by every host or by every network semantics.

### Claim N2 — response equality is model-relative

Whenever the manuscript writes

`Z_i=Z_j`,

it must specify at least:

- response level (`Xi`, richer `Omega`, or ordinary folded model);
- geometry/fixed host;
- host size if relevant;
- connected simple-support convention.

No equality result may be silently promoted across these levels.

## 3. Geometry claims

### Claim G1 — strict 1D permanent memory

**Allowed claim.** In the exact `Xi` model on every even path, all three generic-odd interior fiber members remain pairwise distinguishable.

**Do not claim.** All one-dimensional graph models or all path-like physical systems have the same property.

### Claim G2 — complete outerplanar `Xi` classification

**Allowed claim.** For even outerplanar host size `n>=4`, the exact geometry-class `Xi` response has three classes for every interior pair except `(2,1)`, where the mixed rank-swap pair collides and the pure state remains distinct.

**Do not claim.** This is a complete classification for richer `Omega`-labelled network semantics.

### Claim G3 — planar results are exact where stated, not globally classified

**Allowed claim.** Exact planar results include the Platonic host theorem and numerous larger-order capacity-specific closures.

**Do not claim.** A complete planar classification for all `(P,Q)` and all host sizes.

**Explicit open item.** Universal Gaussian `(6,5)` order-46 `r=17` closure is not proved.

## 4. Regular-factorizable host theorem

### Claim R1 — exact fixed-host universality

**Allowed claim.** Let `H` be connected, simple, even-order, `d`-regular, and 1-factorizable. For uniform `Xi=(A,O)` with `A+O>=d`, the exact fixed-host Pareto front is determined by `(n,d,A,O)` through the formula in `REGULAR_FACTORIZABLE_HOST_ORBITAL_MEMORY_THEOREM.md`.

**Do not claim.** Every `d`-regular graph has this response.

### Claim R2 — topology-blindness has a precise scope

**Allowed claim.** Within the hypotheses of R1 and in the regime `A+O>=d`, two such hosts with the same `(n,d)` have the same uniform `Xi` response.

**Do not claim.** Host topology is irrelevant in general.

### Claim R3 — universal degree filtration

For one generic-odd interior fiber `P>Q>0` on a host satisfying R1 with `d<=P+Q`, the exact class count is

- `3` for `d<P`;
- `2` for `P<=d<P+Q`;
- `1` for `d=P+Q`.

**Interpretation allowed.** Accessible regular degree acts as an operational interface budget that filters orbital information.

**Interpretation forbidden.** This proves that the `P`-orbit physically activates before the `Q`-orbit.

### Claim R4 — underfull regime is not automatic

For `A+O<d`, 1-factorizability alone does not imply connected zero-boundary closure.

**Allowed sufficient condition.** A connected spanning union of the required number of 1-factors gives closure.

**Do not claim.** Necessity or an exact general classification of the underfull regime.

### Claim R5 — fixed host versus geometry class

RFH is a fixed-host theorem. It becomes an exact geometry-class theorem only when an independent extremality argument proves no admissible host in the class can improve the bounds.

Approved examples:

- complete host for unrestricted simple support;
- tetrahedron/octahedron/icosahedron at their planar orders.

## 7. World/tomography side line

### Claim W1

**Allowed claim.** For the exact `61^6` laboratory, full typed/Pareto world-geometry interaction is nonzero while a scalar minimum observable can have zero mixed interaction.

**Do not claim.** Scalar observables are generally useless or always blind.

### Claim W2

Linear response projections commute with the world Laplacian and can only preserve or annihilate existing eigenspace components; they do not move signal between eigenvalues.

**Critical caveat.** Pareto minimization / scalar minimum is nonlinear and is not covered by this linear projection theorem.

### Claim W3

All positive weighted minima determine the lower positive convex envelope, not the discrete Pareto support.

### Claim W4

The tomographic-dimension results are exact for the stated finite world family and observation family. Do not promote the value `2` from the `61` split laboratory into a universal invariant.

Publication placement: optional consequences section; can be removed without damaging the main paper.

## 9. Novelty ledger

### Potentially novel composed results to emphasize

Subject to final literature audit, the paper's claimed contribution should be phrased around the **composition** of known ingredients:

1. intrinsic arithmetic direction-orbit data refining the HATTER folded interface;
2. exact classification of information lost by the fold;
3. exact operational network visibility of that lost data;
4. geometry-dependent orbital-memory laws;
5. the regular-factorizable host degree filtration `3 -> 2 -> 1`;
6. explicit demonstration that restricted probes/coarse observations induce different information-loss relations.

### Classical ingredients not to claim as new

Do not claim novelty for:

- orbit/stabilizer theory;
- quadratic splitting laws;
- perfect matchings / 1-factorizations as classical graph notions;
- Tutte's theorem;
- standard planar/outerplanar edge bounds;
- standard graph Laplacians or star spectra;
- support-function / convex-duality facts by themselves;
- ideal-group freeness / unique prime-ideal factorization;
- classical reduced binary quadratic forms.

Novelty, if sustained after literature audit, lies in the arithmetic-interface/network composition and the exact filtration/collision theorems.

## 10. Publication wording guardrails

Prefer:

- `exact in the Xi model`;
- `for the stated generic-odd interior fiber`;
- `on the fixed host H`;
- `for the geometry class at this order, by extremality`;
- `sufficient condition`;
- `operational memory / forgetting`;
- `response classes`.

Avoid unless independently proved:

- `universal` without listing the host/model hypotheses;
- `curvature` for commuting finite differences;
- `physical port activation`;
- `complete planar classification`;
- `topological invariant`;
- `canonical strongest-first rule`;
- `all quadratic fields` when the theorem is generic odd imaginary-quadratic.
