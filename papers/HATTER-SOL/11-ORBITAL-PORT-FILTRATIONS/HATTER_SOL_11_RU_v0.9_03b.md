# HATTER-SOL-11 · RU v0.9 · часть 3b

### Теорема 7.4 — полная классификация перестановки смешанных рангов

Для любого `P>Q>0` и чётного `n>=4`

\[
\boxed{
Z_{O,n}^{\Xi}(P,Q)=Z_{O,n}^{\Xi}(Q,P)
\iff
(P,Q)=(2,1).
}
\]

**Доказательство.** Если `Q>=3`, минимальные осевые показатели равны `phi_n(P)` и `phi_n(Q)` и различаются по строгой монотонности.

Пусть `Q=1` или `2`, а `P>=3`. В состоянии `(P,Q)` осевой канал ёмкости `P` не может быть насыщен во всех вершинах внешнепланарного графа, поэтому `B_A>0`. В переставленном состоянии `(Q,P)` осевой канал можно насытить на `H_n`: при `Q=1` используем совершенное паросочетание, при `Q=2` — гамильтонов цикл. Дополняющий набор рёбер удовлетворяет ограничению степени `P`.

Два канальных множества рёбер разбивают `E(H_n)`, поэтому их объединение есть весь связный `H_n`. Условие связности HATTER относится к этому объединению; отдельные канальные подграфы не обязаны быть связными. Следовательно, переставленный ответ содержит Парето-точку с `B_A=0`, а исходный — нет. Случай `(2,1)` дан Предложением 7.3. ∎

### Теорема 7.5 — полный закон внутреннего внешнепланарного слоя

Для любого `P>Q>0`

\[
\boxed{
\nu_{O,n}^{\Xi}(P,Q)=
\begin{cases}
2,&(P,Q)=(2,1),\\
3,&\text{иначе}.
\end{cases}}
\]

Смешанные состояния не сталкиваются с чистым. Для Type I при `P>=3` чистый ответ имеет нулевой осевой показатель, а смешанный — положительный минимальный осевой показатель; `(2,1)` разбирается явно. Для Type II при `Q>=3` работает тот же аргумент. Если `Q=1` или `2`, минимальный наклонный показатель переставленного состояния равен `phi_n(P)`, а чистое состояние имеет показатель `psi_n(P+Q)`. При `P=3` это `2` против `6` либо `n+6`; при `P>=4`

\[
\psi_n(P+Q)-\phi_n(P)=nQ>0.
\]

Следовательно, смешанное и чистое состояния не совпадают. ∎
