## Publication result

HATTER-SOL-10 extends the typed factor-network construction from principal/UFD element factorizations to arbitrary imaginary-quadratic ideal factorizations through the chain

`prime-ideal factorization -> minimal principalization witnesses -> witness-state sets -> principalization-residue fibers -> typed network optimization`.

Closed results include:

- integer principalization cost `delta(I)` and its least-norm inverse-class interpretation;
- exact recovery of the principal/UFD HATTER-SOL-09 model;
- nonprincipal ideals with multiple and incomparable typed witness states;
- failure of nodewise Pareto pruning;
- witness-switching gain and an exact host-size phase-transition law;
- a purity theorem on even complete hosts;
- residue/composition injectivity;
- residue-enforced mixed witness phases;
- residue-refined response with exact block convolution, while the fully interacting network remains non-multiplicative because cross-edges can improve the block baseline.

The deferred orbital-port filtration idea is intentionally kept outside this publication in `FUTURE_ORBITAL_PORTS_SEED.md` as a possible later branch.
