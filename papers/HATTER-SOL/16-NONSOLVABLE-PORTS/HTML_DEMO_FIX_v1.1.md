# HATTER-SOL-16 · HTML demo correction v1.1

The first interactive visualization used inline handlers and implicit browser globals created from element IDs. That pattern is fragile in sandboxed, strict, or embedded HTML viewers and can leave visible controls non-responsive.

The corrected standalone demo shipped in the Zenodo R2 package uses:

- `DOMContentLoaded` for initialization;
- explicit `document.getElementById(...)` lookups;
- `addEventListener(...)` for every control;
- no inline `onclick` handlers;
- no dependence on implicit element globals;
- a visible JavaScript startup self-test;
- working Golden 7A / Golden 7B / unknown-signature buttons;
- working Play / Pause / Step / Reset controls and time slider;
- no external JavaScript or CSS dependencies.

The demo also corrects the clock interpretation of the supplied testbench. Since the clock is generated by

```verilog
always #5 clk = ~clk;
```

the full period is 10 ns, i.e. 100 MHz. Inputs applied at 30 ns and 40 ns are captured at 35 ns and 45 ns because they are placed halfway before the next positive edge.

No mathematical H16 claim changes. Orbit IDs 42 and 43 remain demonstration LUT entries; the complete canonical 114-entry ROM belongs to H17.

`ENGINEERING_LAB/HATTER_SOL_16_PSL27_HTML_DEMO_v1.1_FIXED.html`
