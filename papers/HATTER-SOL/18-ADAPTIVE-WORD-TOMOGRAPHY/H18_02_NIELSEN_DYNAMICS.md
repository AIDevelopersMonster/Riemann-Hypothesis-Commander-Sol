## 1. From words to moves

H18 does not only change the query word.  It also studies transformations of the generating pair itself.

We use the elementary moves

\[
S(A,B)=(B,A),
\]

\[
I_A(A,B)=(A^{-1},B),
\qquad
I_B(A,B)=(A,B^{-1}),
\]

\[
N_A(A,B)=(AB,B),
\]

together with the related moves

\[
N_B(A,B)=(A,BA),
\qquad
N_A^{-1}(A,B)=(AB^{-1},B).
\]

Each move preserves generatingness and descends to a permutation of the 114 simultaneous-conjugacy orbit states.

Build the undirected graph on the 114 states generated by

\[
S,\ I_A,\ N_A.
\]

\[
\boxed{36,\ 32,\ 32,\ 14}.

\[

Thus the 114 H17 states do not form one connected Nielsen dynamical world under these standard generators.

## 4. Commutator invariant

For

\[
K=[A,B]=ABA^{-1}B^{-1},
\]

the four components have class distributions:

- size 36: \(36\times3A\);
- size 32: \(32\times4A\);
- size 32: \(32\times4A\);
- size 14: \(7\times7A+7\times7B\).

This is exactly what one expects from the classical fact that Nielsen moves preserve the commutator up to conjugacy and inversion.

The computation reveals one sharper point:

\[
\boxed{
\text{commutator class does not distinguish the two 32-state }4A\text{ components.}
}
\]

So there is at least one additional invariant of the generated Nielsen action hidden inside the \(4A\) sector.

Finding that invariant is now a concrete theoretical target.

## 5. Relation to adaptive tomography

The adaptive tree of H18-01 asks which query best separates the current candidate set.

The Nielsen graph asks how the state moves under free-group automorphisms.

These are dual views:

\[
q_w(\alpha\cdot x)
\quad\leftrightarrow\quad
q_{\alpha(w)}(x),
\]

up to the chosen action convention.

Thus one can either move the state and keep the observer fixed, or keep the state fixed and move the word.

This is the structural bridge between adaptive word tomography and Nielsen dynamics.
