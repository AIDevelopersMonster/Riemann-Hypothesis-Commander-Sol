## 1. Why H18

H17 uses a fixed observer family.

H18 asks:

\[
\boxed{
\text{what changes if the next group word is chosen adaptively?}
}
\]

Instead of evaluating all probes in advance, the observer becomes a branching program:

\[
w_1
\rightarrow
c_1
\rightarrow
w_2(c_1)
\rightarrow
c_2
\rightarrow\cdots
\]

The state being observed therefore controls the future observation path.

This is the natural next theoretical layer after H17.

## 3. H18-A · exact adaptive decision depth

Let \(\mathcal W_L\) be a frozen finite word pool, initially all reduced words up to primitive length \(L\), modulo the same equivalences used by the H17 observer machinery.

For each word:

\[
w\in\mathcal W_L,
\]

define its class-valued query:

\[
q_w([(A,B)])
=
\operatorname{class}(w(A,B)).
\]

Goal:

\[
\boxed{
D^\ast(\mathcal W_L)
=
\min_T
\max_{x\in X}
\operatorname{depth}_T(x)
}
\]

where \(T\) is an adaptive decision tree that identifies all 114 orbits exactly.

Tasks:

1. compute exact optimum \(D^\ast\);
2. certify impossibility below \(D^\ast\);
3. minimize secondary cost:
   - total nodes;
   - average depth;
   - total primitive word length;
   - max word length;
4. emit deterministic certificate and tree.

## 4. H18-B · adaptive versus non-adaptive separation

For the same word pool compare:

\[
D_{\mathrm{adaptive}}
\]

against minimum fixed probe count:

\[
m_{\mathrm{fixed}}.
\]

The theorem question is:

\[
\boxed{
\text{when does branching strictly beat fixed observation?}
}
\]

Need exact finite examples and, if possible, a structural criterion.

## 5. H18-C · adaptive erasure / fault model

H17 robust8 solves one known erasure in a fixed codeword.

H18 should ask a different question:

> if a query fails, can the observer branch around the failed measurement?

Model:

\[
q_w(x)=\mathrm{ERASED}
\]

with known failed query.

Search for adaptive trees satisfying exact identification under one query erasure.

Compare:

- fixed robust8;
- adaptive no-erasure tree;
- adaptive one-erasure tree.

This creates a direct bridge back to hardware.

## 6. H18-D · Nielsen dynamics on orbit space

Study transformations generated by:

\[
S:(A,B)\mapsto(B,A),
\]

\[
I:(A,B)\mapsto(A^{-1},B),
\]

\[
N:(A,B)\mapsto(AB,B).
\]

These descend to permutations/actions on the 114 orbit states.

Tasks:

1. compute exact orbit-state transition permutations;
2. decompose each generator into cycles;
3. compute connected components under the generated action;
4. identify preserved invariants;
5. relate components to commutator class and other trace/class data;
6. compute Schreier graph spectrum and diameter;
7. determine whether adaptive query trees can be aligned with this dynamics.

## 7. H18-E · dynamic words

Allow recursion:

\[
W_{n+1}=\Psi(W_n,A,B)
\]

or dynamic generator pairs:

\[
(A_{n+1},B_{n+1})=\Phi(A_n,B_n).
\]

Observe the class sequence:

\[
c_n=\operatorname{class}(W_n(A,B)).
\]

Questions:

- eventual periods;
- preperiods;
- orbit separation by finite histories;
- minimal history length;
- robustness of history signatures;
- whether temporal signatures beat static probe sets.

This is the transition from tomography to:

\[
\boxed{\text{non-Abelian dynamical tomography}}.
\]

## 8. H18-F · hardware interpretation

Only after the exact tree/dynamics are known.

Candidate processor:

\[
(A,B)
\rightarrow
\text{query controller}
\rightarrow
\text{shared word engine}
\rightarrow
\text{single class engine}
\rightarrow
\text{branch}
\rightarrow
\text{state ID}.
\]

Potential advantage over H17 robust8:

- fewer class evaluations on average;
- one reusable classifier;
- lower switching activity;
- early exit for easy states.

Potential disadvantage:

- controller/state memory;
- data-dependent latency;
- branch logic;
- worse worst-case timing/throughput.

The hardware question is therefore not “adaptive is better”, but:

\[
\boxed{
\text{for which cost model does adaptive tomography win?}
}
\]

## 9. First publication threshold

H18 becomes publishable as a standalone theorem/computational paper when all of the following exist:

1. exact canonical word pool;
2. exact minimum adaptive depth certificate;
3. impossibility certificate for one smaller depth;
4. deterministic optimal or Pareto-optimal tree;
5. exact comparison with fixed probes;
6. complete Nielsen transition graph;
7. at least one nontrivial theorem relating the adaptive and dynamical views.

RTL is optional for the first H18 publication.

## 10. First strike

Start with reduced words of length at most four.

Compute:

\[
D^\ast(\mathcal W_4)
\]

exactly.

Then answer:

1. is depth 3 impossible?
2. is depth 4 sufficient?
3. what is the minimum average depth among depth-4 trees?
4. how many distinct words are needed globally by an optimal tree?
5. which first query minimizes the worst partition?

Only after this exact layer is closed move to erasure-adaptive trees and Nielsen dynamics.

## 12. Research principle

H17 showed that a fixed family of group words can be a code.

H18 asks whether a family of group words can instead be a **program**.

\[
\boxed{
\text{fixed fingerprint}
\longrightarrow
\text{adaptive interrogation program}
}
\]

That is the central idea of H18.
