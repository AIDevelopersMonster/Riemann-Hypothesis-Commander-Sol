## Description

HATTER-SOL-08 studies how arithmetic refinement in factor-capacity networks depends on the admissible geometric graph class. For a capacity vector `c` and a graph class `C`, the free-boundary optimum is

\[
\lambda_C(\mathbf c)=\sum_i c_i-2M_C(\mathbf c),
\]

where `M_C` is the maximum number of edges in a connected simple `C`-graph satisfying the capacity bounds.

The paper proves an exact 1D law showing that multiplicative refinement cannot produce refinement inversion on a strict line. It then exhibits architecture-dependent sign reversal and proves a planar suppression theorem for the split

\[
2q\to(2,q):
\qquad
\Delta_{planar}^{\max}(2,q)
\le
2\left\lceil\frac{3(q-2)}4\right\rceil-(q-2).
\]

By contrast, the unrestricted / 3D value inherited from HATTER-SOL-07 is exactly

\[
\Delta_{3D}^{\max}(2,q)=q-2.
\]

Hence for every `q>=6`, the planar worst-case refinement-inversion amplitude is strictly smaller than the unrestricted one, yielding an infinite planar-versus-3D separation family. The publication also records a hostile-audit counterexample invalidating a stronger naive outerplanar analogue.

The deposit contains synchronized English and Russian v1.0 PDFs with five explanatory figures.
