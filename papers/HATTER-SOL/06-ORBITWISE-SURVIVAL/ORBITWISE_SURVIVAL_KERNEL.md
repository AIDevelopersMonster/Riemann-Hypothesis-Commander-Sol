# HATTER-SOL-06 · Orbitwise Survival Kernel

## 0. Objective

HATTER-SOL-05 replaced the very strong Higher-Fiber Infinitude hypothesis by Cone-Fiber Infinitude (CFI). The next question is sharper:

\[
\boxed{
\text{what is the exact minimal support-orbit condition for a seed symmetry to survive?}
}
\]

The point of this note is to remove the remaining unnecessary cone-wide infinitude assumption and isolate the exact extension data that are actually visible to a chosen partial automorphism.

We work with

\[
\Pi=(\mathbb P,D),
\qquad
D(q,p)\iff q\mid p-1,
\]

Pratt height \(h\), truncations \(P_{\le n}\), layers \(L_n\), and

\[
G_n=\operatorname{Aut}(\Pi\upharpoonright P_{\le n}).
\]

For an admissible exact support

\[
S\subseteq P_{\le n},
\qquad
\max_{q\in S}h(q)=n,
\]

put

\[
X_S=\{p\in L_{n+1}:\operatorname{Pred}(p)=S\},
\qquad
\mu_n(S)=|X_S|.
\]

The Multiplicity Tower Theorem gives

\[
g\in G_n\text{ extends to }G_{n+1}
\iff
\mu_n(S)=\mu_n(gS)
\quad\text{for every admissible }S.
\]

The goal is to determine exactly which of these equalities are genuinely nontrivial after causal localization.

---

# 1. Seed and causal cone

Fix a seed symmetry

\[
\tau\in G_m.
\]

Let

\[
A=\operatorname{supp}(\tau)
\]

and let

\[
C=C^+(A)
\]

be the forward cone generated by the moved seed vertices.

We are interested in extensions that remain causally localized:

\[
g(p)=p
\qquad(p\notin C).
\]

For \(n\ge m\), define

\[
\mathcal T_n^C(\tau)
=
\left\{
 g\in G_n:
 g|_{P_{\le m}}=\tau,
\quad
 g(p)=p\text{ for }p\in P_{\le n}\setminus C
\right\}.
\]

These are the cone-localized partial extensions of \(\tau\) to height \(n\).

Because every \(g\in\mathcal T_n^C(\tau)\) fixes the complement of \(C\) pointwise, it preserves

\[
C\cap P_{\le n}
\]

setwise.

---

# 2. Active supports

Define the active support set at height \(n\) by

\[
\mathcal A_n(C)
=
\left\{
 S\subseteq P_{\le n}:
 S\text{ finite},
\max h(S)=n,
\ S\cap C\ne\varnothing
\right\}.
\]

Supports outside \(\mathcal A_n(C)\) are causally inert for cone-localized motion.

Indeed, if

\[
S\cap C=\varnothing,
\]

then every \(q\in S\) is fixed by \(g\), so

\[
gS=S.
\]

Moreover, by the generated-cone localization lemma from HATTER-SOL-05,

\[
X_S\subseteq\mathbb P\setminus C.
\]

Thus the entire fiber may be fixed pointwise in any cone-localized extension.

This immediately shows that cone-wide conditions on supports disjoint from \(C\) are unnecessary.

---

# 3. Orbitwise balance

Let

\[
g\in\mathcal T_n^C(\tau).
\]

Since \(g\) preserves \(C\cap P_{\le n}\) setwise, it acts on \(\mathcal A_n(C)\).

For \(S\in\mathcal A_n(C)\), let

\[
\mathcal O_g(S)
=
\{g^kS:k\in\mathbb Z\}
\]

be its support orbit.

## Definition 3.1 — orbitwise balance

A support orbit \(\mathcal O\subseteq\mathcal A_n(C)\) is **balanced** if

\[
\mu_n(S)=\mu_n(T)
\qquad
(S,T\in\mathcal O).
\]

Equivalently,

\[
\mu_n(S)=\mu_n(gS)
\qquad
(S\in\mathcal O).
\]

The partial automorphism \(g\) is **orbitwise balanced at height \(n\)** if every active support orbit is balanced.

Fixed support orbits

\[
gS=S
\]

are automatically balanced and impose no arithmetic condition.

Hence the only genuinely nontrivial data are the multiplicity colors on moved active support orbits.

---

# 4. Exact one-step orbitwise criterion

## Theorem 4.1 — cone-localized one-step survival

Let

\[
g\in\mathcal T_n^C(\tau).
\]

Then the following are equivalent:

1. there exists
   \[
   \widetilde g\in\mathcal T_{n+1}^C(\tau)
   \]
   with
   \[
   \widetilde g|_{P_{\le n}}=g;
   \]
2. \(g\) is orbitwise balanced on \(\mathcal A_n(C)\);
3. for every moved active support
   \[
   S\in\mathcal A_n(C),
   \qquad gS\ne S,
   \]
   one has
   \[
   \boxed{\mu_n(S)=\mu_n(gS).}
   \]

### Proof

Assume (1). By the Multiplicity Tower Theorem,

\[
\mu_n(S)=\mu_n(gS)
\]

for every admissible support \(S\), hence in particular for every active support. Therefore every active orbit is balanced, so (1) implies (2).

The equivalence of (2) and (3) is immediate: fixed supports satisfy the equality tautologically, so only moved active supports need to be tested.

Now assume (3). Let \(S\) be any admissible support at height \(n\).

If

\[
S\cap C=\varnothing,
\]

then generated-cone localization gives

\[
gS=S,
\qquad
X_S\subseteq\mathbb P\setminus C.
\]

We extend \(g\) by fixing \(X_S\) pointwise.

If

\[
S\cap C\ne\varnothing,
\]

then \(S\in\mathcal A_n(C)\). If \(gS=S\), again no multiplicity comparison is needed. If \(gS\ne S\), hypothesis (3) gives

\[
\mu_n(S)=\mu_n(gS).
\]

Choose a bijection

\[
\beta_S:X_S\to X_{gS}.
\]

Every vertex of \(X_S\) lies in \(C\), because \(S\cap C\ne\varnothing\) and \(C\) is forward closed. Performing this construction orbit by orbit gives an extension

\[
\widetilde g\in G_{n+1}
\]

which fixes every next-layer vertex outside \(C\). Hence

\[
\widetilde g\in\mathcal T_{n+1}^C(\tau).
\]

Thus (3) implies (1). \(\square\)

---

# 5. Minimality at one height

Theorem 4.1 gives an exact local answer.

For cone-localized one-step survival:

- no condition is needed on supports disjoint from \(C\);
- no condition is needed on active supports fixed by \(g\);
- every moved active orbit contributes exactly one constancy requirement for the multiplicity coloring.

Therefore the relevant arithmetic object is not the full function

\[
S\mapsto\mu_n(S),
\]

but its restriction to the moved active support orbits of the actual partial automorphism.

Equivalently, if

\[
c_n(S)=\mu_n(S),
\]

then one-step survival says precisely that \(g\) is an automorphism of the multiplicity-colored active-support hypergraph

\[
(\mathcal A_n(C),c_n).
\]

This is the first exact replacement of cone-wide CFI by an orbitwise criterion.

---

# 6. The cone-localized extension tree

Define the rooted extension tree

\[
\mathscr T_C(\tau)
=
\bigsqcup_{n\ge m}\mathcal T_n^C(\tau),
\]

where

\[
g_{n+1}\succ g_n
\]

when

\[
g_{n+1}|_{P_{\le n}}=g_n.
\]

By Theorem 4.1, a node

\[
g_n\in\mathcal T_n^C(\tau)
\]

has at least one child if and only if it is orbitwise balanced at height \(n\).

Thus the arithmetic obstruction to extension is completely concentrated at the dead nodes of this tree.

## Definition 6.1 — immediate orbitwise killing witness

A moved active orbit

\[
\mathcal O\subseteq\mathcal A_n(C)
\]

is an immediate killing witness for \(g_n\) if \(\mu_n\) is not constant on \(\mathcal O\).

Then

\[
\boxed{
g_n\text{ is a leaf of }\mathscr T_C(\tau)
\iff
\text{an immediate orbitwise killing witness exists}.}
\]

---

# 7. Exact global survival criterion

## Theorem 7.1 — orbitwise global survival

The seed \(\tau\) admits a global automorphism extension

\[
g\in\operatorname{Aut}(\Pi)
\]

fixing every prime outside \(C\) if and only if there exists a compatible sequence

\[
g_m,g_{m+1},g_{m+2},\dots
\]

such that

\[
g_n\in\mathcal T_n^C(\tau),
\qquad
 g_{n+1}|_{P_{\le n}}=g_n,
\]

and every \(g_n\) is orbitwise balanced at height \(n\).

Equivalently,

\[
\boxed{
\tau\text{ survives globally outside-fixed}
\iff
\mathscr T_C(\tau)\text{ has an infinite branch}.}
\]

### Proof

A global cone-localized automorphism gives its compatible finite-height restrictions, and each restriction must be orbitwise balanced by Theorem 4.1.

Conversely, a compatible infinite branch defines, by union over Pratt height, a permutation of all primes. Every edge lies in some finite truncation, so the union is a graph automorphism. Each node fixes the complement of \(C\) at its height, hence the union fixes every prime outside \(C\). \(\square\)

This is necessary and sufficient and contains no infinitude hypothesis.

---

# 8. Why finite-horizon survival is still not enough

It is possible for a rooted tree to have nodes at arbitrarily large finite depths but no infinite branch when branching is not compact.

For example, a root may have children indexed by \(N\), with the \(N\)-th child continuing for exactly \(N\) further levels and then dying. Every finite target depth is reachable, but no single compatible branch survives forever.

Therefore the statement

\[
\forall N\ \exists g_N\in\mathcal T_N^C(\tau)
\]

is not, in the mixed infinite-fiber regime, equivalent to global survival.

The missing information is compatibility through one persistent branch.

This is precisely the noncompact phenomenon already left open by HATTER-SOL-05.

---

# 9. Transfinite pruning and the survival kernel

The exact global object can be isolated by pruning dead branches.

Let

\[
\mathscr T^{(0)}=\mathscr T_C(\tau).
\]

For an ordinal \(\alpha\), define recursively

\[
\mathscr T^{(\alpha+1)}
=
\left\{
 g\in\mathscr T^{(\alpha)}:
 g\text{ has a child in }\mathscr T^{(\alpha)}
\right\},
\]

and at a limit ordinal \(\lambda\),

\[
\mathscr T^{(\lambda)}
=
\bigcap_{\alpha<\lambda}\mathscr T^{(\alpha)}.
\]

Continue until stabilization and write

\[
\mathscr K_C(\tau)
=
\bigcap_\alpha\mathscr T^{(\alpha)}.
\]

We call \(\mathscr K_C(\tau)\) the **orbitwise survival kernel**.

## Theorem 9.1 — kernel criterion

A node \(g\in\mathscr T_C(\tau)\) lies in \(\mathscr K_C(\tau)\) if and only if there exists an infinite branch of \(\mathscr T_C(\tau)\) starting at \(g\).

In particular,

\[
\boxed{
\tau\text{ survives globally outside }C
\iff
\tau\in\mathscr K_C(\tau).
}
\]

### Proof

Every node on an infinite branch survives every pruning stage: if a node is retained at stage \(\alpha\), its next node on the branch is also retained at stage \(\alpha\), so it is retained at stage \(\alpha+1\); limit stages follow by intersection.

Conversely, after stabilization every node of \(\mathscr K_C(\tau)\) has a child in \(\mathscr K_C(\tau)\). By dependent choice, repeatedly select such a child. This produces an infinite branch. \(\square\)

The kernel formulation is the exact coinductive survival criterion.

---

# 10. Obstruction rank

If a node is eventually deleted by the pruning process, define its **orbitwise obstruction rank** by the usual well-founded recursion

\[
\operatorname{rk}(g)
=
\sup\{\operatorname{rk}(\widetilde g)+1:
\widetilde g\succ g\}.
\]

A leaf has rank \(0\).

Interpretation:

- rank \(0\): immediate multiplicity mismatch on a moved active support orbit;
- finite rank \(r\): death after at most \(r+1\) further extension stages;
- infinite ordinal rank: every finite-depth search can be beaten by choosing another branch, yet no compatible infinite branch exists.

The last case is the precise mathematical form of **noncompact death**.

This gives a new trichotomy for a seed:

\[
\boxed{
\text{finite killing}
\quad/\quad
\text{transfinite noncompact killing}
\quad/\quad
\text{global survival}.}
\]

---

# 11. Recovery of the FFC theorem

Under the finite-fiber condition (FFC), every Pratt truncation is finite. Hence every level of \(\mathscr T_C(\tau)\) is finite and the tree is finitely branching.

By König's infinity lemma,

\[
\forall N\ \mathcal T_N^C(\tau)\ne\varnothing
\Longrightarrow
\mathscr T_C(\tau)\text{ has an infinite branch}.
\]

Therefore under FFC there is no transfinite noncompact death.

## Corollary 11.1

Under FFC, if \(\tau\) does not survive globally, then its obstruction rank is finite.

Equivalently, global death is witnessed at a finite Pratt height by a finite obstruction tree.

Thus the finite-fiber compactness theorem from HATTER-SOL-05 is exactly the compact special case of the orbitwise survival kernel.

---

# 12. Recovery and sharpening of CFI

Suppose CFI\((\tau)\) holds:

\[
\mu(S)=\aleph_0
\qquad
\text{for every finite exact support }S\text{ with }S\cap C\ne\varnothing.
\]

Then every active support orbit of every cone-localized partial extension is automatically balanced, since all its multiplicities equal \(\aleph_0\).

Hence every node of \(\mathscr T_C(\tau)\) has a child.

By dependent choice, the tree has an infinite branch.

Therefore the Causal Survival Theorem follows immediately.

But the exact criterion is weaker in structure:

- active fixed supports may have arbitrary multiplicity;
- moved supports need only have equal multiplicities along the particular support orbit;
- those equal multiplicities may be finite;
- no condition is required on active support orbits never encountered by the chosen surviving branch.

Thus CFI is a convenient uniform sufficient condition, while the orbitwise survival kernel is the exact condition.

For the actual prime graph we do **not** claim that CFI is strictly stronger as an arithmetic theorem; accidental equivalence remains possible. The strict weakening is at the level of the formal extension criterion.

---

# 13. Specialization to \(\tau=(3\ 5)\)

For the primary HATTER-SOL seed

\[
\tau=(3\ 5),
\qquad
C_\tau=C^+(\{3,5\}),
\]

HATTER-SOL-05 proved

\[
d_{\mathbb P}(C_\tau)=1,
\]

indeed already within directed distance at most two from \(3\).

The new result says that density-one causal reach is not itself the survival condition.

The exact condition is:

\[
\boxed{
(3\ 5)\text{ survives globally}
\iff
\mathscr K_{C_\tau}(\tau)\ne\varnothing
}
\]

with the seed node lying in that kernel.

At each height we need inspect only the moved active support orbits generated by the currently chosen partial extension.

This is a much smaller logical target than proving cone-wide infinitude of every exact fiber.

---

# 14. New research target after the first strike

The structural problem is now reduced to a sharper arithmetic/combinatorial question.

For \(\tau=(3\ 5)\), determine whether the kernel dies because of:

1. an immediate low-height moved support orbit with unequal multiplicities;
2. a finite obstruction tree at some larger height;
3. a genuinely noncompact transfinite obstruction in the mixed finite/infinite regime;
4. or no obstruction at all, yielding a global automorphism.

The next strike should therefore attack the **first reachable moved active support orbits** and classify which multiplicity equalities are forced by the actual extension choices.

A useful working object is the branch-dependent set

\[
\mathcal R(g_\bullet)
=
\bigcup_{n\ge m}
\{S\in\mathcal A_n(C):g_nS\ne S\},
\]

for a compatible candidate branch \(g_\bullet\).

The minimal arithmetic burden of that branch is exactly

\[
\boxed{
\mu_n(S)=\mu_n(g_nS)
\quad
\text{for every }S\in\mathcal R(g_\bullet).
}
\]

No other support multiplicities are needed for that branch's survival.
