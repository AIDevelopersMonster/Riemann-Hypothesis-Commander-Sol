# HATTER-SOL-21 · SCALAR-FIBER GRAPH COUPLING TARGET

Status: **NEXT ACTIVE THEOREM STRIKE**

## 1. Fixed projective observer code

Condition on:

- the quadratic-character stratum;
- the unordered reciprocal projective support-code pair.

At this point, each directional observer sees the same declared projective
support class as the other pairs in the stratum.

What remains is the scalar-fiber coordinate.

## 2. Fiber coordinates

Write

\[
q\bmod h_p
=
r_p+k_p e_p,
\]

\[
p\bmod h_q
=
r_q+k_q e_q.
\]

For every supported nonzero observer level, H21-PG2 supplies a unique graph
value

\[
k_c(r).
\]

A bit is zero exactly when

\[
k=k_c(r)
\]

for optional levels, or for every \(k\) when the bit is forced.

Thus the local mask is generated by equality tests in the scalar fibers.

## 3. Reduced reciprocal problem

After the projective code is fixed, the unexplained coupling is controlled by
events of the form

\[
\boxed{
k_p=f_{W,p}(r_p)
}
\]

and

\[
\boxed{
k_q=f_{W,q}(r_q).
}
\]

The core question becomes:

\[
\boxed{
\text{Are reciprocal prime-selected scalar phases }k_p,k_q
\text{ equidistributed relative to the graph values }f(r)?
}
\]

## 4. First exact candidate

For each direction define the scalar mismatch variable

\[
u_p
=
k_p-f_{W,p}(r_p)
\pmod{d_p}.
\]

Optional zero incidence is exactly

\[
u_p=0.
\]

Similarly define \(u_q\).

The same-mask problem reduces to the joint law of

\[
(u_p,u_q).
\]

This removes the observer graph itself from the final random variable and
places the arithmetic question in normalized scalar-fiber coordinates.

## 5. Theorem target

Seek a structural relation or bound on

\[
\Pr[u_p=0,u_q=0]
\]

relative to

\[
\Pr[u_p=0]\Pr[u_q=0].
\]

Possible mechanisms:

- reciprocity in the scalar subgroups \(D_p,D_q\);
- discrete-log relations induced by
  \[
  q\bmod h_p,\quad p\bmod h_q;
  \]
- norm constraints;
- character-dependent affine shifts;
- shared divisors of \(d_p,d_q\).

## 6. Publication gate relevance

A theorem controlling the normalized scalar residuals \(u_p,u_q\) would be the
first result to attack the **remaining H21-specific reciprocal mechanism**
rather than a generic covariance decomposition.

If such a theorem survives broad-family testing and prior-art audit, the
publication threshold should be reconsidered immediately.
