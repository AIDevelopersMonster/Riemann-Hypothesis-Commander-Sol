# HATTER-SOL-21 · NORM-LIFT / DOUBLE-COVER SCALAR THEOREM

Status: **EXACT LOCAL THEOREM / PUBLICATION-GATE RELEVANT**

## 1. Setup

Fix a nonexceptional quadratic world at prime \(p\).

Let

\[
H_p=\langle x\rangle,
\qquad
h_p=e_p d_p,
\]

where

\[
e_p=|H_p/(H_p\cap\mathbf F_p^\times)|
\]

is the projective clock and

\[
d_p=|D_p|,
\qquad
D_p=H_p\cap\mathbf F_p^\times.
\]

Put

\[
\lambda_p=x^{e_p}\in\mathbf F_p^\times.
\]

Then

\[
D_p=\langle\lambda_p\rangle
\]

and

\[
\operatorname{ord}(\lambda_p)=d_p.
\]

The norm of the distinguished generator is

\[
N(x)=x\tau(x)=-C.
\]

## Theorem H21-NL1 — norm-square law

The scalar generator satisfies

\[
\boxed{
\lambda_p^2=(-C)^{e_p}.
}
\]

Hence if

\[
t_p=\operatorname{ord}_{\mathbf F_p^\times}(-C)
\]

and

\[
s_p=
\operatorname{ord}_{\mathbf F_p^\times}((-C)^{e_p})
=
\frac{t_p}{\gcd(t_p,e_p)},
\]

then

\[
\boxed{
\frac{d_p}{\gcd(d_p,2)}
=
s_p.
}
\]

### Proof

Since \(\lambda_p=x^{e_p}\) is scalar,

\[
N(\lambda_p)=\lambda_p^2.
\]

But by multiplicativity of norm,

\[
N(\lambda_p)
=
N(x)^{e_p}
=
(-C)^{e_p}.
\]

The order of \(\lambda_p^2\) in a cyclic group generated by \(\lambda_p\) is

\[
d_p/\gcd(d_p,2).
\]

The order of \((-C)^{e_p}\) in \(\mathbf F_p^\times\) is

\[
t_p/\gcd(t_p,e_p).
\]

Therefore the two quantities are equal. QED.

## Corollary H21-NL2 — scalar-fiber size has only two possibilities

Let

\[
s_p=\frac{t_p}{\gcd(t_p,e_p)}.
\]

Then

\[
\boxed{
d_p\in\{s_p,2s_p\}.
}
\]

Moreover:

- \(d_p=s_p\) is possible only when \(s_p\) is odd;
- if \(s_p\) is even, necessarily
  \[
  \boxed{d_p=2s_p.}
  \]

Thus the projective clock \(e_p\) and base-field order \(t_p\) determine the
scalar-fiber size up to at most one binary lift choice.

## 2. Scalar coordinate from the norm

For an incoming exponent \(m\), write

\[
m=r+k e_p
\]

with

\[
0\le r<e_p.
\]

The scalar coordinate is

\[
z_p(m)=\lambda_p^k=x^{m-r}\in D_p.
\]

Its square is

\[
\boxed{
z_p(m)^2=(-C)^{m-r}.
}
\]

Therefore the norm determines the scalar coordinate through the squaring map

\[
D_p\to D_p,
\qquad
z\mapsto z^2.
\]

## Corollary H21-NL3 — odd-fiber collapse

If \(d_p\) is odd, squaring is an automorphism of \(D_p\).

Hence

\[
\boxed{
z_p(m)
=
\left((-C)^{m-r}\right)^{(d_p+1)/2}.
}
\]

Thus once the projective phase \(r=m\bmod e_p\) is known, the scalar coordinate
is determined entirely by the norm datum.

There is no additional scalar ambiguity.

## Corollary H21-NL4 — even fiber is a two-sheeted lift

If \(d_p\) is even, the squaring map on \(D_p\) has kernel

\[
\{+1,-1\}.
\]

For every admissible norm value in its image, the scalar coordinate has exactly
two possible lifts:

\[
\boxed{
z,\ -z.
}
\]

Equivalently, the exponent coordinate \(k\pmod{d_p}\) is determined by the
norm only modulo

\[
d_p/2,
\]

with one remaining binary sheet bit.

Thus the full local phase geometry is

\[
\boxed{
\text{projective phase}
+
\text{norm scalar coordinate}
+
\text{at most one lift bit}.
}
\]

## 3. Canonical lift bit

Let

\[
s_p=\operatorname{ord}(\lambda_p^2).
\]

If

\[
d_p=2s_p,
\]

then

\[
\boxed{
\lambda_p^{s_p}=-1.
}
\]

The two solutions of a scalar norm equation differ by this central element.

Define the lift sheet of \(k\) by its class in the two-element quotient

\[
\boxed{
\mathbf Z/d_p\mathbf Z
\big/
\mathbf Z/s_p\mathbf Z.
}
\]

This is the only scalar information not visible to the norm-square coordinate.

## 4. Observer consequence

By H21-SF1, every optional zero bit is an equality

\[
z_p(m)=t_j(r).
\]

### Odd \(d_p\)

The optional incidence is determined entirely by

\[
r
\]

and

\[
(-C)^{m-r}.
\]

No discrete scalar-fiber coordinate remains.

### Even \(d_p\)

The norm determines whether the target is compatible up to sign:

\[
z_p(m)^2=t_j(r)^2.
\]

If compatible, the observer must still choose between the two sheets

\[
+t_j(r),\quad -t_j(r).
\]

Hence all residual scalar complexity is a binary sign/lift decision.

## 5. Reciprocal H21 reduction

For a semiprime \(pq\), after projective reduction:

- odd-fiber directions are completely norm-determined;
- even-fiber directions carry one residual lift bit.

Therefore the unresolved reciprocal scalar coupling cannot require arbitrary
large cyclic coordinates.

It reduces to:

\[
\boxed{
\text{norm compatibility}
+
\text{binary lift correlation in even fibers}.
}
\]

This is a substantially stronger reduction than the raw
\(u_p\in\mathbf Z/d_p\mathbf Z\) formulation.

## 6. Publication significance

The norm-square identity is classical algebra, but the reduction of the H21
zero-mask observer to projective phase + norm datum + at most one binary lift
bit is specific to the current observer architecture.

Publication relevance depends on whether the reciprocal lift bits obey a
nontrivial arithmetic relation or yield a concrete compiler/hardware
simplification surviving prior-art audit.
