# HATTER-SOL-14 · First Equivariant Homology Separation Witness

**Status:** exact positive theorem candidate

## 1. General cycle-space representation formula

Let `Gamma` be a finite abelian group and

\[
C=\operatorname{Cay}(\Gamma,S)
\]

a connected simple undirected Cayley graph. Decompose the inverse-closed connection set as

\[
S=igsqcup_{j=1}^{p}\{s_j,s_j^{-1}\}\sqcup T,
\]

where each `s_j` has order greater than two and `T` is the set of involutions contained in `S`.

Over `Q`, the cellular chain modules satisfy

\[
C_0(C;\mathbb Q)\cong\mathbb Q[\Gamma].
\]

Each non-involutory pair contributes one free edge orbit, hence one copy of the regular module `Q[Gamma]` to `C_1`. For an involution `tau`, the corresponding undirected edge orbit has stabilizer `<tau>`; translation by `tau` reverses the chosen edge orientation. Thus its oriented edge module is

\[
\operatorname{Ind}_{\langle\tau\rangle}^{\Gamma}\varepsilon_\tau,
\]

where `epsilon_tau` is the nontrivial one-dimensional representation of the order-two subgroup.

Since the graph is connected, the exact chain sequence gives in the rational representation ring

\[
\boxed{
[H_1(C;\mathbb Q)]
=
(p-1)[\mathbb Q\Gamma]
+
\sum_{\tau\in T}
[\operatorname{Ind}_{\langle\tau\rangle}^{\Gamma}\varepsilon_\tau]
+[\mathbf1].
}
\]

Dimension check:

\[
\dim H_1
=|E|-|V|+1
=\frac{|\Gamma|(2p+|T|)}2-|\Gamma|+1.
\]

The displayed representation formula has exactly the same dimension.

## 2. Arithmetic world `k=8`

For

\[
m_8=2^8-1=255=3\cdot5\cdot17,
\]

we have

\[
\Gamma_8=(\mathbb Z/255\mathbb Z)^\times/\langle2\rangle,
\qquad
|\Gamma_8|=\frac{\varphi(255)}8=16.
\]

Using the Chinese remainder decomposition of the unit group and quotienting by the order-eight subgroup generated by `2`, one obtains

\[
\boxed{\Gamma_8\cong C_2\oplus C_8.}
\]

Write the group additively. Let

\[
a=(1,0),\qquad b=(0,1),\qquad c=4b=(0,4).
\]

Then `a`, `c`, and `a+c` are the three nonzero involutions.

Define

\[
S_1=\{b,-b,a,c\},
\qquad
S_2=\{b,-b,a+c,c\}.
\]

Both sets are inverse-closed, exclude zero, and generate `Gamma_8`. Hence

\[
C_i=\operatorname{Cay}(\Gamma_8,S_i)
\]

are connected simple Galois-equivariant carriers.

Both have

\[
|V|=16,\qquad d=4,\qquad |E|=32.
\]

Under the H13/H14 capacity `k=8`, both have the same scalar boundary

\[
\boxed{B_f=16(8-4)=64.}
\]

## 3. The carriers are abstractly isomorphic

Define an automorphism `phi` of `Gamma_8` by

\[
\phi(a)=a+c,
\qquad
\phi(b)=b.
\]

Since `c=4b`, this is an involutive group automorphism. It fixes `c` and sends

\[
S_1\mapsto S_2.
\]

Therefore

\[
\boxed{C_1\cong C_2}
\]

as abstract graphs. In particular they have the same ordinary graph invariants, including the same orientable genus.

## 4. But the equivariant homology modules differ

For both carriers we have `p=1` and two involution generators. Therefore

\[
[H_1(C_1;\mathbb Q)]
=
[\operatorname{Ind}_{\langle a\rangle}^{\Gamma_8}\varepsilon_a]
+
[\operatorname{Ind}_{\langle c\rangle}^{\Gamma_8}\varepsilon_c]
+[\mathbf1],
\]

while

\[
[H_1(C_2;\mathbb Q)]
=
[\operatorname{Ind}_{\langle a+c\rangle}^{\Gamma_8}\varepsilon_{a+c}]
+
[\operatorname{Ind}_{\langle c\rangle}^{\Gamma_8}\varepsilon_c]
+[\mathbf1].
\]

Because `Gamma_8` is abelian, the character of

\[
\operatorname{Ind}_{\langle\tau\rangle}^{\Gamma_8}\varepsilon_\tau
\]

has value `-8` at `tau` and value `0` at every element outside `<tau>`.

Evaluate at `a`.

For `C_1`, the `a`-summand contributes `-8`, the `c`-summand contributes `0`, and the trivial summand contributes `1`. Thus

\[
\chi_{H_1(C_1)}(a)=-7.
\]

For `C_2`, the element `a` belongs neither to `<a+c>` nor to `<c>`, so both induced summands contribute `0`, while the trivial summand contributes `1`. Thus

\[
\chi_{H_1(C_2)}(a)=1.
\]

Hence the rational `Gamma_8`-modules are not isomorphic:

\[
\boxed{
H_1(C_1;\mathbb Q)
\not\cong
H_1(C_2;\mathbb Q)
\quad\text{as }\mathbb Q[\Gamma_8]\text{-modules}.
}
\]

## Theorem H14.10 — equivariant homological memory is strictly finer

There exist two Galois-equivariant HATTER carriers in the same arithmetic world (`k=8`) that have

- the same vertex number;
- the same degree;
- the same scalar boundary;
- the same abstract graph isomorphism type;
- therefore the same ordinary orientable genus;

but non-isomorphic rational equivariant first-homology modules.

Thus

\[
\boxed{
\text{scalar boundary data + ordinary graph topology}
\;<\;
\text{equivariant homological data}.
}
\]

More sharply, even the **abstract graph itself** does not determine the `Gamma_8`-module structure on `H_1` unless the arithmetic action is retained.

## Programme consequence

The scalar H14 symmetry hypotheses closed negatively, but the equivariant homology layer is genuinely richer. The next target is to classify this representation for general `Gamma_k` and determine whether the separation can be made infinite/asymptotic rather than a single `k=8` witness.
