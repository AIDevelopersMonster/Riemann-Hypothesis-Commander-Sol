## Main result

For

\[
S_{\mathbb P}(n,p)\iff p\in\mathbb P\text{ and }p=n+1,
\]

we prove

\[
\boxed{
\operatorname{Aut}(\mathbb N_{>0},\times,S_{\mathbb P})
=\{\mathrm{id}\}.
}
\]

The paper also identifies the radical-predecessor layer

\[
R_{\mathbb P}(r,p)\iff r=\operatorname{rad}(p-1)
\]

as the next unresolved rigidity frontier.

## Next research line

**HATTER-SOL-04** is planned around the question

\[
\boxed{
\operatorname{Aut}(\mathbb N_{>0},\times,R_{\mathbb P})
\stackrel{?}{=}
\{\mathrm{id}\}.
}
\]

The aim is to determine whether multiplicities in the factorization of $p-1$ are genuinely necessary for rigidity, or whether the global directed support network already recovers enough information.
