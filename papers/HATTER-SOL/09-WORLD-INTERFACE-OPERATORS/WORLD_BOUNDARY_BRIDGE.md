## 1. Additive unit length

Let `R` be either `Z[i]` or `Z[omega]`, and let `U(R)` be its finite unit group. Define

\[
\rho_R(\alpha)
:=
\min\left\{k:\alpha=\varepsilon_1+\cdots+\varepsilon_k,
\;\varepsilon_j\in U(R)\right\}.
\]

Equivalently, `rho_R(alpha)` is the word distance from `0` to `alpha` in the additive Cayley graph generated by the units.

### Proposition 1.1 — unit and conjugation invariance

For every unit `u` and every `alpha in R`,

\[
\boxed{\rho_R(u\alpha)=\rho_R(\alpha)}.
\]

Also

\[
\boxed{\rho_R(\bar\alpha)=\rho_R(\alpha)}.
\]

**Proof.** Multiplication by a unit permutes the unit generating set, so it induces an automorphism of the additive Cayley graph fixing zero. Conjugation also permutes the units and fixes zero. Hence both preserve word distance. □

### Proposition 1.2 — recovery of the HATTER-SOL-07 scalar capacity

For every rational integer `m`,

\[
\boxed{\rho_R(m)=|m|}.
\]

Thus the new world-capacity agrees exactly with the old scalar capacity on the embedded integer line.

## 2. Closed formulas in the two worlds

### 2.1 Gaussian / square world

For

\[
\alpha=a+bi,
\]

the unit steps are `±1, ±i`, so

\[
\boxed{\rho_G(a+bi)=|a|+|b|}.
\]

This is the usual Manhattan/Mannheim lattice weight.

After quotienting by units and conjugation, each nonzero Gaussian integer has a canonical chamber representative

\[
A+Bi,
\qquad A\ge B\ge0,
\]

and

\[
\rho_G=A+B.
\]

### 2.2 Eisenstein / triangular world

Use

\[
\omega^2+\omega+1=0.
\]

For

\[
\alpha=a+b\omega,
\]

the additive unit steps are

\[
\pm1,\;\pm\omega,\;\pm\omega^2.
\]

In `(a,b)` coordinates these are

\[
\pm(1,0),\quad\pm(0,1),\quad\pm(1,1).
\]

Hence

\[
\boxed{
\rho_E(a+b\omega)
=
\max\{|a|,|b|,|a-b|\}
}
\]

or equivalently

\[
\boxed{
\rho_E(a+b\omega)
=
\frac{|a|+|b|+|a-b|}{2}.
}
\]

This is the hexagonal weight: the minimum number of unit steps in the triangular/hexagonal lattice.

After quotienting by units and conjugation, choose the fundamental 30-degree chamber

\[
A+B\omega,
\qquad A\ge 2B\ge0.
\]

Then

\[
\boxed{\rho_E=A}.
\]

Indeed

\[
A+B\omega=(A-B)\cdot1+B(1+\omega),
\]

so a shortest path uses `A-B` steps in one unit direction and `B` steps in the adjacent unit direction, for total `A`.

This gives a useful preliminary two-interface interpretation: the canonical nonnegative interface counts in the chamber are

\[
\boxed{(A-B,B)}
\]

and their sum is the scalar world-capacity `rho_E=A`.

No claim is made yet that this ordered pair is the final typed-port invariant.

## 3. Smith normal form audit

For the quadratic regular block

\[
M_F(L,W)=
\begin{pmatrix}
L&uW\\
W&L+vW
\end{pmatrix},
\]

put

\[
g=\gcd(L,W).
\]

Since the entries include both `L` and `W`, the gcd of all matrix entries is exactly `g`. For nonzero norm,

\[
\det M_F(L,W)=N_F(L,W).
\]

Therefore the Smith normal form is

\[
\boxed{
\operatorname{SNF}M_F(L,W)
=
\operatorname{diag}\left(g,\frac{|N_F(L,W)|}{g}\right).
}
\]

### Consequence 3.1

If `pi` is a primitive factor of rational prime norm `p`, then `g=1`, so

\[
\boxed{\operatorname{SNF}M_F(\pi)=\operatorname{diag}(1,p)}.
\]

For an inert rational prime represented by the scalar element `p`,

\[
M_F(p)=pI,
\qquad
\boxed{\operatorname{SNF}(pI)=\operatorname{diag}(p,p)}.
\]

Thus SNF records the coarse split/inert distinction, but for primitive split factors it loses the directional geometry completely: all primitive norm-`p` factors have the same SNF `(1,p)`. SNF is therefore rejected as the sole HATTER-SOL port-capacity invariant.

## 4. Canonical world factor-capacity profile

Both `Z[i]` and `Z[omega]` are UFDs. For a positive integer `n>1`, choose a full irreducible factorization in `R`:

\[
n=u\pi_1\cdots\pi_k.
\]

Define the **world factor-capacity profile**

\[
\boxed{
\mathcal C_R(n)
:=
\{\rho_R(\pi_1),\ldots,\rho_R(\pi_k)\}
}
\]

as a multiset, counting multiplicity.

### Theorem 4.1 — well-definedness

`C_R(n)` is independent of the chosen irreducible factorization.

**Proof.** Unique factorization changes irreducible factors only by permutation and multiplication by units. Proposition 1.1 makes `rho_R` invariant under the latter. □

Now apply the HATTER-SOL-07 free-boundary functional to this capacity profile:

\[
\boxed{
\Lambda_R(n)
:=
\lambda\bigl(\mathcal C_R(n)\bigr).
}
\]

For a one-element profile `(c)`, use the natural connected one-vertex convention

\[
\lambda((c))=c.
\]

This is the first canonical bridge

\[
\boxed{
\text{world factorization}
\longrightarrow
\text{unit-invariant integer capacities}
\longrightarrow
\text{HATTER-SOL-07 network boundary}.
}
\]

## 5. Rational-prime boundary theorem

Let `p` be a rational prime.

### Theorem 5.1 — Gaussian world

1. If `p=2`, then `p` ramifies through `1+i`, whose world-capacity is `2`, hence

\[
\mathcal C_G(2)=(2,2),
\qquad
\boxed{\Lambda_G(2)=2}.
\]

2. If

\[
p\equiv3\pmod4,
\]

then `p` is inert, so

\[
\mathcal C_G(p)=(p),
\qquad
\boxed{\Lambda_G(p)=p}.
\]

3. If

\[
p\equiv1\pmod4,
\]

write in the canonical square chamber

\[
p=A^2+B^2,
\qquad A\ge B>0,
\]

and put

\[
r_G(p)=A+B.
\]

Then the two conjugate prime factors both have capacity `r_G(p)`, so

\[
\boxed{
\mathcal C_G(p)=(r_G,r_G),
\qquad
\Lambda_G(p)=2r_G-2.
}
\]

The boundary release from the integer-line node is

\[
p-\Lambda_G(p)
=p-2(A+B)+2
\]

and therefore

\[
\boxed{
p-\Lambda_G(p)=(A-1)^2+(B-1)^2>0
}
\]

for every split prime `p>=5`.

### Theorem 5.2 — Eisenstein world

1. If `p=3`, then `p` ramifies through an Eisenstein prime of hexagonal weight `2`, hence

\[
\boxed{\Lambda_E(3)=2}.
\]

2. If

\[
p\equiv2\pmod3,
\]

then `p` is inert, so

\[
\boxed{\Lambda_E(p)=p}.
\]

3. If

\[
p\equiv1\pmod3,
\]

write a prime factor in the canonical triangular chamber as

\[
\pi=A+B\omega,
\qquad A\ge2B\ge0,
\]

with

\[
p=A^2-AB+B^2.
\]

Put

\[
r_E(p)=A.
\]

Then

\[
\boxed{
\mathcal C_E(p)=(r_E,r_E),
\qquad
\Lambda_E(p)=2r_E-2.
}
\]

Moreover

\[
\frac34r_E^2\le p\le r_E^2,
\]

so a split Eisenstein prime has

\[
\Lambda_E(p)=O(\sqrt p)
\]

whereas an inert rational prime has `Lambda_E(p)=p`.

## 6. World contrast and the 7 / 53 mirror

Define the two-world contrast

\[
\boxed{
D_{E-G}(n)
:=
\Lambda_E(n)-\Lambda_G(n).
}
\]

For `7`:

- Gaussian: inert, so `Lambda_G(7)=7`;
- Eisenstein: `7=(3+omega)(3+omega^2)`, the canonical factor has `(A,B)=(3,1)` and `r_E=3`, so `Lambda_E(7)=4`.

Therefore

\[
\boxed{D_{E-G}(7)=-3}.
\]

For `53`:

- Gaussian: `53=(7+2i)(7-2i)`, so `r_G=9` and `Lambda_G(53)=16`;
- Eisenstein: inert, so `Lambda_E(53)=53`.

Therefore

\[
\boxed{D_{E-G}(53)=+37}.
\]

Thus the pair `7,53` produces a strict sign reversal of the HATTER-SOL world contrast:

\[
\boxed{
D_{E-G}(7)<0<D_{E-G}(53).
}
\]

This sign reversal is not a new splitting theorem; it is a new candidate network response built by composing classical splitting with the HATTER-SOL boundary.

## 7. Mod-12 prime phase law

For primes `p>3`, the simultaneous Gaussian/Eisenstein splitting type is determined by `p mod 12`.

### Theorem 7.1

For rational primes `p>3`:

#### `p == 5 mod 12`

Gaussian split, Eisenstein inert. Therefore

\[
\boxed{
D_{E-G}(p)
=p-(2r_G(p)-2)>0.
}
\]

Since

\[
\sqrt p\le r_G(p)\le\sqrt{2p},
\]

we have

\[
\boxed{
\frac{D_{E-G}(p)}p\to1
}
\]

along the prime sequence `p == 5 mod 12`.

#### `p == 7 mod 12`

Gaussian inert, Eisenstein split. Therefore

\[
\boxed{
D_{E-G}(p)
=(2r_E(p)-2)-p<0.
}
\]

Since

\[
\sqrt p\le r_E(p)\le\frac{2}{\sqrt3}\sqrt p,
\]

we have

\[
\boxed{
\frac{D_{E-G}(p)}p\to-1
}
\]

along the prime sequence `p == 7 mod 12`.

#### `p == 11 mod 12`

Both worlds are inert, so

\[
\boxed{D_{E-G}(p)=0}.
\]

#### `p == 1 mod 12`

Both worlds split, so

\[
\boxed{
D_{E-G}(p)=2(r_E(p)-r_G(p)).
}
\]

In particular

\[
D_{E-G}(p)=O(\sqrt p),
\qquad
\boxed{
D_{E-G}(p)/p\to0
}.
\]

The sign in the doubly split class is not fixed by congruence alone.

### Interpretation

The two-world HATTER-SOL response has three asymptotic scales:

- one-world split / one-world inert: macroscopic contrast `±p+O(sqrt(p))`;
- both inert: exactly zero contrast;
- both split: mesoscopic contrast `O(sqrt(p))`.

Dirichlet's theorem supplies infinitely many primes in each nonzero residue class `1,5,7,11 mod 12`, so the positive and negative macroscopic contrast phases both occur infinitely often.

## 8. Prime-power network closure

The prime case has at most two factor nodes. Prime powers activate the genuine HATTER-SOL network optimization.

For a uniform capacity profile

\[
(c,c,\ldots,c)
\]

on `k` vertices, zero free boundary is possible exactly when there exists a connected `c`-regular simple graph. For `c>=2`, this occurs whenever

\[
k\ge c+1
\quad\text{and}\quad
kc\ \text{is even}.
\]

Define the **first closure exponent**

\[
\boxed{
\tau_R(p)
:=
\min\{m\ge1:\Lambda_R(p^m)=0\}.
}
\]

### Theorem 8.1 — inert prime

For an odd rational prime `p` inert in `R`, the factorization of `p^m` has `m` irreducible factors, each of capacity `p`. Therefore

\[
\boxed{\tau_R(p)=p+1}.
\]

At `m=p+1`, the complete graph `K_{p+1}` saturates every capacity exactly.

### Theorem 8.2 — split prime

If `p` splits in `R` and each conjugate prime factor has world-capacity `r_R(p)`, then `p^m` has `2m` irreducible factors, all of capacity `r_R(p)`. Because `2m*r_R(p)` is automatically even,

\[
\boxed{
\tau_R(p)
=
\left\lceil\frac{r_R(p)+1}{2}\right\rceil.
}
\]

Thus a split prime reaches a completely closed HATTER-SOL network after only `O(sqrt(p))` powers, whereas an inert prime first closes at exponent `p+1`.

### Laboratory values

For `7`:

\[
\boxed{
\tau_G(7)=8,
\qquad
\tau_E(7)=2.
}
\]

Indeed the triangular-world factor profile of `7^2` is `(3,3,3,3)`, saturated by `K_4`.

For `53`:

\[
\boxed{
\tau_G(53)=5,
\qquad
\tau_E(53)=54.
}
\]

The square-world factor profile of `53^5` has ten capacity-9 nodes and is saturated by `K_{10}`, while the triangular world keeps `53` inert and requires the first complete saturation at `K_{54}`.

This is the first result in the branch where the world-dependent factorization feeds a genuinely nontrivial HATTER-SOL network closure phenomenon.

## 9. What is closed, what remains open

### Closed

1. Raw `(L,W)` coordinate sums are rejected as noncanonical port counts.
2. Additive unit word length `rho_R` gives a canonical integer world-capacity.
3. `rho_R(m)=|m|` recovers HATTER-SOL-07 on the integer line.
4. Full factorization gives a well-defined capacity multiset `C_R(n)`.
5. `Lambda_R(n)=lambda(C_R(n))` is therefore well-defined.
6. Exact rational-prime formulas are proved.
7. The mod-12 world-contrast phase law is proved.
8. The first closure exponent of prime powers is proved.
9. SNF is too coarse to serve as the final geometric capacity by itself.

### Open

1. Preserve a genuinely **typed two-interface** structure beyond the scalar word capacity without losing unit invariance.
2. Determine the correct edge-consumption law for typed interfaces.
3. Study general composite `n`, where different world factor profiles have different numbers and sizes of nodes.
4. Define and test a commutation defect between `factor first -> world network` and any future `network first -> world lift` construction.
5. Only after natural maps between worlds are identified, investigate an operator/Laplacian on the world graph.
