# HATTER-SOL 20-21 publication package

This directory is the release-oriented source package for the combined H20-H21 architecture/compiler paper.

## Source of truth

- `paper.md` - publication manuscript source.
- `references.bib` - audited bibliography.
- `BUILD.md` - reproducible PDF/LaTeX build commands.
- `RELEASE_MANIFEST.md` - freeze checklist.

The exploratory H20-EXT line remains closed and is not promoted to a positive claim.

## Claim

H20 supplies finite two-vendor evidence that formally equivalent arithmetic presentations can remain physically distinguishable.

H21 supplies an exact descriptor-level (B=0) specialization to a scalar Euler-Jacobi observer, followed by matched RTL and Cyclone V measurement.

Author names/affiliations are intentionally left unresolved until archival release.
