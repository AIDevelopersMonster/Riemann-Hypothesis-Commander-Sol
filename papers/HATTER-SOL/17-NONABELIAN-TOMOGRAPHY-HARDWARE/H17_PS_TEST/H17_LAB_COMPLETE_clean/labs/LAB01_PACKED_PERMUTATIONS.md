# LAB-01 — Перестановки и 24-битное представление

## Цель

Понять, что именно приходит на вход H17 core и как перестановка восьми точек превращается в 24-битное слово.

## Теория

Каждое p(i) лежит в диапазоне 0…7 и занимает 3 бита:

~~~text
p[2:0]   = p(0)
p[5:3]   = p(1)
...
p[23:21] = p(7)
~~~

Итого 8 x 3 = 24 бита.

Identity permutation имеет packed value:

~~~text
fac688
~~~

В RTL compose(p,q) реализует p o q, то есть (p o q)(i)=p(q(i)). inverse строит обратную перестановку.

## Задание

1. Открыть rtl/verilog/h17_core.v.
2. Найти compose и inverse.
3. Открыть rtl/verilog/h17_tables.vh.
4. Найти identity row.
5. Выбрать три group_row и выписать class code и 24-битную перестановку.
6. Объяснить, почему произвольное 24-битное слово не обязано быть перестановкой и не обязано принадлежать PSL(2,7).
