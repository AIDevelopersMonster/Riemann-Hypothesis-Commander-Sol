# Теория H17-LAB-01 в четырёх уровнях

## Уровень A — без алгебры

Представим объект, описанный восемью связанными признаками:

~~~text
[x1][x2][x3][x4][x5][x6][x7][x8]
~~~

Каждый признак принимает одно из шести допустимых значений. Стираем один:

~~~text
[x1][x2][ ?][x4][x5][x6][x7][x8]
~~~

Если система признаков построена удачно, оставшихся семи достаточно, чтобы однозначно восстановить восьмой.

Важно: речь идёт не о произвольных 12.5% любого файла, а об одной координате специально построенного математического описания.

## Уровень B — инженерный

Каждая координата занимает 3 бита. Восемь координат дают 24 бита.

Class codes:

~~~text
0 = 1A
1 = 2A
2 = 3A
3 = 4A
4 = 7A
5 = 7B
7 = erased marker
~~~

Пример:

~~~text
raw_signature = 8d256a
              = 100 011 010 010 010 101 101 010
codes         =   4   3   2   2   2   5   5   2
classes       =  7A  4A  3A  3A  3A  7B  7B  3A
~~~

При стирании первой координаты:

~~~text
raw      = 8d256a
observed = ed256a
repaired = 8d256a
~~~

Это known erasure: номер потерянной координаты известен.

## Уровень C — математический

Пусть G = PSL(2,7), |G| = 168. В лаборатории элементы G представлены перестановками восьми точек проективной прямой P^1(F_7).

Вход:

(A,B) in G x G.

Одновременное сопряжение:

(A,B) ~ (hAh^-1, hBh^-1).

Для generating pairs рассматриваются 114 simultaneous-conjugacy orbits.

Используются восемь слов:

~~~text
w1 = AAB
w2 = Abb
w3 = AAAB
w4 = Abbb
w5 = AABAb
w6 = AAbAb
w7 = ABABB
w8 = ABaBB
~~~

где a=A^-1 и b=B^-1.

Если c(g) — код класса сопряжённости, то fingerprint:

F(A,B) = ( c(w1(A,B)), ..., c(w8(A,B)) ).

## Уровень D — почему одно известное стирание восстанавливается

Рассмотрим generating fingerprints как конечный код C_gen в алфавите из шести классов.

Для robust8 family установлено:

d_gen/gen >= 2,
d_gen/non >= 2.

Если удалить одну заранее известную координату j и две разные generating signatures после удаления совпадут, то до удаления они различались бы только в координате j. Их расстояние было бы 1, что противоречит d_gen/gen >= 2.

Следовательно, удаление любой одной известной координаты сохраняет однозначность generating signature.

Условие d_gen/non >= 2 не даёт после одного стирания спутать generating state с реализуемым non-generating state.

## Почему 1663 такта

LAB-01 переиспользует маленький последовательный datapath:

~~~text
168      membership scan
1        CHECK
34       буквы восьми words
8 x 168  class scans
1        MASK
114      orbit scan
1        FINISH
----------------
1663
~~~

Поэтому 1663 — свойство reference architecture. Параллельная схема может вычислять тот же объект быстрее ценой большей логики.

## Что доказывает regression

Успешный полный regression означает, что RTL совпал с golden model на опубликованном наборе тест-векторов. Это не то же самое, что target-specific FPGA timing или измерение физического устройства.
