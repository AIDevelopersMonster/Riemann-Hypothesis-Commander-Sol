# Руководство преподавателя — H17-LAB-01

## Учебная идея

Один объект объясняется на четырёх языках:

~~~text
обычная интуиция
    ->
теория кодирования
    ->
конечные группы
    ->
цифровая схемотехника
~~~

Начинающей группе не обязательно начинать с PSL(2,7). Удобно сначала показать LAB-03 как «семь признаков восстановили восьмой», а затем разбирать причину.

## Типичные ошибки

- «Восстановили 12.5% любого файла» — нет, одну координату специально построенного fingerprint.
- «7 — ещё один conjugacy class» — нет, это marker.
- «status=0 означает только processing» — нет, после done это также non-PSL input.
- «1663 — фундаментальная граница» — нет, latency LAB-01.
- «CRC проверяет математику» — нет, CRC проверяет транспорт.
- «PASS означает FPGA готова» — нет.
