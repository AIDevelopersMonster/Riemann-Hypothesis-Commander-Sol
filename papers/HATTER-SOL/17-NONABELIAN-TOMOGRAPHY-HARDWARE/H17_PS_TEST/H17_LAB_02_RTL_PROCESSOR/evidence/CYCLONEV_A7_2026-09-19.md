# H17-LAB-02 — Cyclone V E A7 benchmark (2026-09-19)

## Target

- Device: 5CEFA7F23C6
- Family: Cyclone V E
- Quartus II: 13.1.0 Build 162 Web Edition
- Reference clock constraint: 100 MHz
- Same H17-LAB-02 RTL as the Cyclone IV baselines

## Synthesis / fit

Quartus completed synthesis, fit, assembly, and TimeQuest successfully.

Resource summary:
- 7,941 / 56,480 ALMs = 14%
- 132 registers
- 40 / 156 DSP blocks = about 26%
- 134 / 240 pins = 56%
- average interconnect usage about 5–6%
- reported peak interconnect usage about 43–50%
- Auto Fit was used; some fitter optimizations were skipped

Important: Quartus inferred 40 DSP elements from the arithmetic in the PSL(2,7) membership / class logic. Therefore this run measures the benefit of the Cyclone V platform as actually mapped by Quartus, not ALM fabric alone.

## Timing

Slow 1100 mV, 85 C:
- Fmax = 27.85 MHz
- worst setup slack at 100 MHz = -25.908 ns
- hold slack = +0.374 ns
- worst data delay = 35.694 ns
- critical path: b_q[14] -> repaired_signature[13]~reg0
- logic levels = 34
- cell delay = 12.726 ns (35%)
- routing delay = 22.969 ns (64%)
- clock skew = -0.114 ns

The critical path still traverses the group-word/classification engine and repair path. The detailed path explicitly passes through Cyclone V DSP blocks for Mult0 and Mult1.

## Comparison with Cyclone IV C7 size-control baseline

Cyclone IV EP4CE22F17C7:
- Fmax = 21.26 MHz
- data delay = 47.404 ns
- logic levels = 68
- cell delay = 16.736 ns
- routing delay = 30.448 ns

Cyclone V 5CEFA7F23C6:
- Fmax = 27.85 MHz
- data delay = 35.694 ns
- logic levels = 34
- cell delay = 12.726 ns
- routing delay = 22.969 ns

Observed changes:
- Fmax: about +31%
- data delay: about -24.7%
- logic levels: 68 -> 34, exactly halved on the selected critical path
- cell delay: about -24%
- routing delay: about -24.6%

This is a substantial platform-level improvement. However it is not a pure LUT/ALM comparison because Cyclone V automatically uses 40 DSP blocks.

## Required control

Run the same device and RTL with AUTO_DSP_RECOGNITION=OFF. This isolates the Cyclone V ALM/routing advantage from DSP inference.
