## Quartus II 13.1 post-fit timing-simulation limitation

An attempted ModelSim post-fit timing run generated:

- h17_lab02_q13_cyclonev_a7.vo
- no .sdo file

This is expected. Quartus II 13.1 does not support gate-level timing simulation for Arria V, Cyclone V, or Stratix V. The EDA Netlist Writer can generate a functional gate-level/post-fit .vo netlist for Cyclone V, but it does not provide the SDF timing annotation required to reproduce fitted cell/routing delays in ModelSim.

Therefore:
- Cyclone IV: post-fit + SDF ModelSim timing waveform is available.
- Cyclone V: physical timing evidence is TimeQuest, not an SDF-backed waveform.
- The 35.694 ns critical-path delay must not be represented as if it had been observed in a Cyclone V ModelSim WLF.
