# Prime-Successor Operator companion note

Companion package to **Prime-Successor Algebra** (Zenodo DOI: **10.5281/zenodo.22077920**).

Contents:

- `article_ru.md` — Russian manuscript source;
- `article_en.md` — English manuscript source;
- `../../demos/prime-successor-operator/index.html` — standalone interactive demonstration;
- publication PDF/DOCX files are generated from the same manuscripts.

Core result:

`U_sigma L_n U_sigma^* = L_{sigma_hat(n)}`

for every permutation of the prime generators. Thus the standard faithful left-regular operator lift preserves the full prime-permutation symmetry; an additional symmetry-breaking datum is necessary for standard prime successor.
