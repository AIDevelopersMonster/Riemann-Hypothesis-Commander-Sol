Core result:

`U_sigma L_n U_sigma^* = L_{sigma_hat(n)}`

for every permutation of the prime generators. Thus the standard faithful left-regular operator lift preserves the full prime-permutation symmetry; an additional symmetry-breaking datum is necessary for standard prime successor.

The current publication line also develops the adelic checkpoint:

`SYMMETRY -> INDIVIDUALIZATION -> CROSS-PRIME COUPLING -> ORIENTATION -> MAGNITUDE`.
