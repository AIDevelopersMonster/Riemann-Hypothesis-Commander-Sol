## Scientific checkpoint

This release freezes the sparse binary anonymous phase theory through:

1. the Componentwise Phase Theorem;
2. the exactness criterion via diagonal realized component cocycles;
3. the cost hierarchy `lambda`, `mu`, `alpha`;
4. `alpha <= mu <= kappa(Lambda)-1`;
5. the unbounded separation family `lambda=r-1`, `alpha=1`;
6. the No-old-obstruction theorem;
7. the deletion-symmetry reformulation;
8. the complete four-point audit and the five-point sparse audit through five defined cells.

The inequality `alpha(D,c) <= lambda(D,c)` is **not** part of the frozen theorem set; it remains Conjecture 14.
