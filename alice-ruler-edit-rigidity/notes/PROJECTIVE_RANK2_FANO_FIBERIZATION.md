## 1. Purpose

The remaining projective problem is the conjectural upper bound

```math
D_{pc}(S,\mathcal P)\le C(1-\rho_P)
```

for sufficiently small projective phase impurity.

This note carries out the first genuinely constructive coordinate-recovery step.

Starting only from

```math
\varepsilon:=1-\rho_P,
```

we prove that one can choose a block

```math
B=\{a,b,c\}
```

whose order-4 Steiner subloop

```math
H=\{0,a,b,c\}\cong C_2^2
```

acts exactly on all but `O(\varepsilon v)` points in 4-point Fano fibers, and such that multiplication between all but `O(\varepsilon v^2)` ordered pairs of fibers is exactly `H`-affine.

Thus the first two Boolean coordinates can be recovered with **linear** loss. The unresolved problem is pushed to the quotient of the Fano fibers.

## 2. Exact Fano count behind `rho_P`

Let

```math
N=\frac{v(v-1)(v-3)}6
```

be the number of independent 3-subsets of the `STS(v)`.

Every P-phase root generates one unique Fano subsystem `STS(7)`. Conversely, a Fano subsystem contains exactly

```math
\binom73-7=28
```

independent triples.

Hence, if `F(S)` denotes the number of Fano subsystems,

```math
\boxed{
F(S)=\frac{|P|}{28}=\frac{\rho_P N}{28}.
}
\tag{2.1}
```

The maximum possible Fano count is therefore

```math
\frac N{28}
=\frac{v(v-1)(v-3)}{168},
```

attained by projective systems.

Thus `rho_P` is literally the density of the maximal possible Fano-plane count.

## 3. Blockwise Fano-extension defect

For a block

```math
B\in\mathcal B(S),
```

let

```math
f(B)
```

be the number of Fano subsystems containing `B`.

Distinct Fano subsystems containing the same block have disjoint sets of four points outside that block: if two such Fanos shared an external point `z`, then the subsystem generated by `B\cup\{z\}` would be both of them.

Therefore

```math
4f(B)\le v-3.
```

Define the **Fano-extension defect**

```math
\boxed{
e(B):=(v-3)-4f(B).
}
\tag{3.1}
```

Equivalently, `e(B)` is exactly the number of external points `z\notin B` for which `B\cup\{z\}` does **not** generate a Fano subsystem.

### Lemma 3.1 (exact global Fano-defect sum)

```math
\boxed{
\sum_{B\in\mathcal B(S)} e(B)
=N(1-\rho_P).
}
\tag{3.2}
```

### Proof

Let

```math
b(v)=\frac{v(v-1)}6
```

be the number of STS blocks. Since every Fano plane contains seven blocks,

```math
\sum_B f(B)=7F(S).
```

Using (2.1),

```math
4\sum_Bf(B)
=28F(S)
=\rho_PN.
```

Also

```math
b(v)(v-3)=N.
```

Therefore

```math
\sum_Be(B)
=N-\rho_PN
=N(1-\rho_P).
```

`\square`

### Remark 3.2 (comparison with Pasch defect)

The previous local Pasch defect was

```math
d(B)=(v-3)-p(B).
```

Every Fano containing `B` contributes four Pasch configurations through `B`, but a Pasch through `B` need not lie in a Fano. Hence

```math
p(B)\ge4f(B),
```

and therefore

```math
\boxed{d(B)\le e(B).}
\tag{3.3}
```

The difference `e(B)-d(B)` measures Pasch extensions through `B` that fail to complete to Fano geometry. This is exactly the phenomenon exposed by the Pasch-trade counterexample in `PROJECTIVE_ASSOCIATOR_BRIDGE.md`.

## 4. Translation commutator defect equals associator defect exactly

Let `L=X\sqcup\{0\}` be the Steiner loop and

```math
T_x(z)=x\circ z.
```

Let

```math
s
=|\{(x,y,z)\in L^3:(x\circ y)\circ z\ne x\circ(y\circ z)\}|.
```

### Lemma 4.1

```math
\boxed{
\sum_{x,y\in L} d_H(T_xT_y,T_yT_x)=s.
}
\tag{4.1}
```

Here `d_H` is the **unnormalized** Hamming distance on permutations of `L`.

### Proof

For fixed `x,y`, the permutations `T_xT_y` and `T_yT_x` differ at `z` exactly when

```math
x\circ(y\circ z)\ne y\circ(x\circ z).
```

By commutativity this is exactly failure of associativity at the ordered triple

```math
(x,z,y),
```

because

```math
(x\circ z)\circ y=y\circ(x\circ z).
```

Summing over `x,y,z` merely permutes the three coordinates of the associator-failure set. `\square`

Thus almost-projective phase gives, with no loss at all, an average almost-commuting family of involutive translations.

The known stability theorem for almost commuting permutations (Arzhantseva--Paunescu) repairs any **fixed** finite tuple; it does not by itself give the required uniform repair for our `n` translations with growing Boolean rank. Therefore (4.1) is useful structure, not yet a black-box solution.

## 5. Point associator load and a clean block

For `x\in L`, define the first-coordinate associator load

```math
A_x
:=
|\{(y,z)\in L^2:(x\circ y)\circ z\ne x\circ(y\circ z)\}|.
\tag{5.1}
```

Then

```math
\sum_{x\in L}A_x=s.
\tag{5.2}
```

The associator bridge gives

```math
s
\le
\varepsilon\,v(v-1)(v-3),
\qquad
\varepsilon=1-\rho_P.
\tag{5.3}
```

Call a nonzero point `x\in X` **row-bad** if

```math
A_x>6\varepsilon (v-1)(v-3).
\tag{5.4}
```

### Lemma 5.1

There are fewer than `v/6` row-bad points.

### Proof

If there were at least `v/6`, their total contribution to (5.2) would exceed

```math
\frac v6\cdot6\varepsilon(v-1)(v-3)
=
\varepsilon v(v-1)(v-3)
\ge s,
```

contradiction (with the strict inequality in the definition handling equality). `\square`

Each point belongs to `(v-1)/2` blocks. Hence the number of blocks meeting the row-bad set is at most

```math
\frac v6\frac{v-1}{2}
=
\frac12\,b(v).
```

So at least half of all STS blocks consist entirely of row-good points.

Combining this with Lemma 3.1 gives:

### Theorem 5.2 (clean base block)

There exists a block

```math
B=\{a,b,c\}
```

such that simultaneously

```math
\boxed{
A_a,A_b,A_c
\le
6\varepsilon(v-1)(v-3)
}
\tag{5.5}
```

and

```math
\boxed{
e(B)\le2\varepsilon(v-3).}
\tag{5.6}
```

### Proof

At least `b(v)/2` blocks contain no row-bad point. The total Fano-extension defect over **all** blocks is `N\varepsilon`. Hence one of those row-good blocks has

```math
e(B)
\le
\frac{N\varepsilon}{b(v)/2}
=2\varepsilon(v-3).
```

`\square`

This is the base block used for coordinate propagation below.

## 6. Exact rank-2 Fano fiberization

Fix the clean block

```math
B=\{a,b,c\}
```

from Theorem 5.2 and put

```math
H=\{0,a,b,c\}.
```

Because `B` is an STS block, `H` is an exact order-4 Boolean subloop:

```math
H\cong C_2^2.
```

Let `R_B` be the set of external points that do not extend `B` to a Fano subsystem:

```math
R_B
:=
\{z\in X\setminus B:\langle B\cup\{z\}\rangle\not\cong S_7\}.
```

By definition,

```math
|R_B|=e(B).
```

Hence Theorem 5.2 gives

```math
\boxed{|R_B|\le2\varepsilon(v-3).}
\tag{6.1}
```

Put

```math
U=L\setminus R_B.
```

Every Fano subsystem containing `B` is an order-8 Boolean subloop containing `H`; its four points outside `H` form one orbit for the regular action of `H` by left translations.

Distinct such Fanos have disjoint external four-sets. Therefore:

### Theorem 6.1 (rank-2 Fano fiberization)

The set `U` admits an exact disjoint decomposition

```math
\boxed{
U
=
H\ \sqcup\ C_1\ \sqcup\cdots\sqcup\ C_q,
}
\tag{6.2}
```

where every `C_i` has four points and

```math
H\cup C_i
```

is an elementary abelian group of order `8` under the original Steiner-loop multiplication.

In particular, for every `h\in H` and every `x\in C_i`,

```math
h\circ x\in C_i,
```

and the action of `H` on `C_i` is regular.

Moreover

```math
q=f(B)
=\frac{v-3-e(B)}4,
```

so the fiberization covers all but at most `2\varepsilon(v-3)` nonzero points.

`\square`

This is an **exact**, not approximate, recovery of the first two Boolean coordinates on a `1-O(\varepsilon)` fraction of the carrier.

## 7. Pairwise affine compatibility between fibers

We now show that multiplication between the recovered `H`-torsors is `H`-affine except on only `O(\varepsilon v^2)` ordered point pairs.

Call an ordered pair `(x,y)\in U^2` **contaminated** if at least one of the following holds:

1. `x\circ y\notin U`;
2. for some `h\in H`,

```math
(h\circ x)\circ y
\ne
h\circ(x\circ y).
\tag{7.1}
```

Let `Z` be the set of contaminated ordered pairs.

### Lemma 7.1 (linear contamination bound)

```math
\boxed{|Z|<20\varepsilon v^2.}
\tag{7.2}
```

### Proof

For condition 1, fix `r\in R_B`. In a quasigroup table each symbol occurs exactly once in each row, so there are exactly `|L|=v+1` ordered pairs `(x,y)\in L^2` with

```math
x\circ y=r.
```

Thus condition 1 contributes at most

```math
|R_B|(v+1)
\le
2\varepsilon(v-3)(v+1).
\tag{7.3}
```

For condition 2, `h=0` never fails. For `h=a,b,c`, the number of pairs `(x,y)` failing (7.1) is exactly `A_h`. By (5.5), their union has size at most

```math
A_a+A_b+A_c
\le
18\varepsilon(v-1)(v-3).
\tag{7.4}
```

Adding (7.3) and (7.4),

```math
|Z|
\le
2\varepsilon(v-3)(v+1)
+18\varepsilon(v-1)(v-3)
```

```math
=2\varepsilon(v-3)(10v-8)
<20\varepsilon v^2.
```

`\square`

## 8. Uncontaminated fiber pairs are exactly `H`-affine

Treat `H` itself as one distinguished fiber. For any `x\in U`, write

```math
[x]
```

for the unique fiber among

```math
H,C_1,\ldots,C_q
```

containing `x`.

Call an ordered fiber pair `(C,D)` **clean** if **every** ordered point pair in `C\times D` is uncontaminated.

Since each contaminated point pair lies in one unique ordered fiber pair, the number of non-clean ordered fiber pairs is at most `|Z|`.

### Theorem 8.1 (exact affine law on a clean fiber pair)

Let `(C,D)` be a clean ordered fiber pair. Choose any

```math
x\in C,
\qquad
y\in D,
```

and put

```math
z=x\circ y.
```

Then `z\in U`, and there is one fiber

```math
E=[z]
```

such that **every** product of a point of `C` with a point of `D` lies in `E`.

More precisely, for every `h,k\in H`,

```math
\boxed{
(h\circ x)\circ(k\circ y)
=(h\circ k)\circ z.
}
\tag{8.1}
```

Thus multiplication `C\times D\to E` is exactly the standard affine/torsor law over

```math
H\cong\mathbb F_2^2.
```

### Proof

Because `(C,D)` is clean, `(x,y)` is uncontaminated, so `z=x\circ y\in U`.

Fix `h,k\in H`. Since `k\circ y\in D`, the pair `(x,k\circ y)` is also uncontaminated. Applying (7.1) with first coordinate `k` to the equivalent ordered pair `(y,x)` and using commutativity gives

```math
x\circ(k\circ y)
=k\circ(x\circ y)
=k\circ z.
\tag{8.2}
```

Likewise `(x,k\circ y)` being uncontaminated gives

```math
(h\circ x)\circ(k\circ y)
=h\circ\bigl(x\circ(k\circ y)\bigr)
=h\circ(k\circ z).
\tag{8.3}
```

Finally `z\in U`. Hence `z` belongs either to `H` or to a Fano fiber `E`. In either case `H\cup E` is an exact Boolean subloop, so

```math
h\circ(k\circ z)
=(h\circ k)\circ z.
```

Combining with (8.3) proves (8.1).

Since `(h\circ k)\circ z` remains in the `H`-orbit/fiber `[z]=E`, every product from `C\times D` lies in the same output fiber. `\square`

### Corollary 8.2 (linear rank-2 quotient error)

Let

```math
\mathcal Q_B=\{H,C_1,\ldots,C_q\}
```

be the recovered fiber set. All but at most

```math
\boxed{20\varepsilon v^2}
```

ordered fiber pairs carry an exact well-defined `H`-affine multiplication law.

Since

```math
|\mathcal Q_B|
=\frac{|U|}{4}
=\frac{v+1-e(B)}4
=\Theta(v),
```

this is an `O(\varepsilon)` fraction of fiber pairs (with an absolute, non-optimized constant).

## 9. What has been constructed

Theorems 6.1 and 8.1 give a concrete two-level description.

After deleting at most

```math
2\varepsilon(v-3)
```

points, the Steiner loop is partitioned into exact copies of the affine 2-bit torsor

```math
H\cong\mathbb F_2^2.
```

For all but `O(\varepsilon v^2)` fiber interactions, multiplication has the exact form

```math
(h,C)\circ(k,D)
=
(h+k,\ C\diamond D)
```

(after choosing one origin in each fiber), where the fiber output `C\diamond D` is well-defined on every clean fiber pair.

So the original reconstruction problem has been reduced, with linear loss, to completing/repairing an **almost-Steiner multiplication on the quotient set of fibers**.

This is the first constructive Boolean-coordinate recovery theorem in the branch.

## 10. Why the proof does not yet iterate automatically

It is tempting to apply the same theorem recursively to the quotient fiber set. At present this is not legitimate.

The quotient multiplication is only defined coherently on all but `O(\varepsilon)` of the fiber pairs. We have not proved that the remaining table can be completed to an exact Steiner quasigroup while changing only `O(\varepsilon q^2)` entries.

That completion statement is essentially a sparse Latin/Steiner repair problem and is exactly where the general Latin-square removal literature is not yet available in the needed form.

Likewise, almost-commuting permutation stability does not close this gap: Arzhantseva--Paunescu prove stability for every **fixed** `k`-tuple of almost commuting permutations, while the number/rank of translations needed here grows with the order. Becker--Mosheiff give polynomial permutation stability for abelian groups, but the quantitative constants are group/presentation dependent and do not immediately furnish a rank-uniform repair of our entire growing translation family.

Thus the obstruction after this note is sharply localized:

> **quotient completion/repair**, not the first Boolean coordinate layer.

---

## 11. Relation to classical exact decomposition

In the exact case `\varepsilon=0`, Theorem 5.2 gives a block with `e(B)=0` and zero row associator load. Then `R_B` is empty, every fiber pair is clean, and the decomposition in Theorem 6.1 is a genuine quotient-by-`H` decomposition of the Boolean Steiner loop.

This is the approximate counterpart of the classical order-4 subloop/coset decomposition phenomena studied for Steiner loops. The present statement is quantitative and permits a linear exceptional set and linear pair error.

1. G. Arzhantseva, L. Paunescu, *Almost commuting permutations are near commuting permutations*, J. Funct. Anal. 269 (2015), 745--757, DOI `10.1016/j.jfa.2015.02.013`. It proves Hamming stability of the commutator for fixed finite tuples.

4. G. Falcone et al., *Extensions of Steiner Triple Systems*, J. Combin. Des. (2025), for exact Veblen-point/Fano-subsystem structure.

No checked source supplies the rank-uniform quotient completion theorem needed to iterate Theorem 8.1 to full projective reconstruction.

## 13. Closed conclusions

For every `STS(v)` with

```math
\varepsilon=1-\rho_P,
```

there exists a block `B` such that:

1. its order-4 subloop `H` is exact Boolean;
2. at most

```math
2\varepsilon(v-3)
```

points fail to belong to a Fano extension of `B`;
3. all remaining points split exactly into 4-point `H`-torsors;
4. at most

```math
20\varepsilon v^2
```

ordered point pairs are contaminated;
5. every uncontaminated fiber pair obeys the exact affine law

```math
(hx)(ky)=(hk)(xy);
```

6. therefore the first two Boolean coordinates are recovered with linear vertex and pair loss;
7. the only remaining obstruction to full linear partial-core stability is a repair/completion theorem for the resulting almost-Steiner quotient.

This is a positive structural theorem, not merely evidence for the conjecture.
