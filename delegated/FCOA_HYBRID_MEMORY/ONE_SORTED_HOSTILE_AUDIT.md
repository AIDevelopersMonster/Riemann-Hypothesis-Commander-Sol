# FCOA Hybrid Memory — One-Sorted Hostile Audit of JFS-3

**Direction:** SOL-HYBRID — Joint Memory of Partial Operations  
**Audit target:** typed JFS-3 and Lift-Compatibility theorem boundary  
**Status:** specific one-sorted witness survives; general one-sorted theorem not yet claimed

## 1. Audit question

The typed JFS-3 witness used an active sort `X={a,b,c}` and a pure common terminal-output sort `O={u,v}`. The hostile question is whether joint rigidity disappears when those sorts are erased and all five elements live in one universe.

The answer for the minimal witness is **no**.

## 2. One-sorted universe and operation tables

Let

\[
U=\{a,b,c,u,v\}.
\]

Define two binary partial operations on the same one-sorted universe by exactly

\[
\boxed{a\oplus a=u,}
\]

\[
\boxed{b\otimes b=u,\qquad c\otimes c=v,}
\]

with every other cell undefined.

The elements `u,v` are terminal only as a consequence of the table: no operation cell has either of them as an argument. No unary predicate, named constant, sort, or external tag says that they are outputs.

## 3. Exact automorphism group of the `\oplus` reduct

The unique defined input pair is `(a,a)`. Therefore every automorphism must fix `a`.

Since

\[
a\oplus a=u,
\]

it must also fix `u`.

The remaining three elements `b,c,v` occur nowhere in the `\oplus` table, neither as inputs nor as outputs. Hence they may be permuted arbitrarily.

Therefore

\[
\boxed{
\operatorname{Aut}(U,\oplus)
\cong S_{\{b,c,v\}}
\cong S_3.
}
\]

Thus the first reduct is highly nonrigid even though the typed active projection had only `C_2`.

## 4. Exact automorphism group of the `\otimes` reduct

The domain consists exactly of the two loops

\[
(b,b),\qquad(c,c).
\]

Hence any automorphism preserves the set `{b,c}`. The element `a` is the unique point that is neither an input to a defined `\otimes` cell nor an output of one, so `a` is fixed.

If `b,c` are fixed individually, then `u,v` are forced fixed by their defining equations.

If

\[
b\leftrightarrow c,
\]

then preservation of values forces

\[
u\leftrightarrow v.
\]

No further permutation is possible. Therefore

\[
\boxed{
\operatorname{Aut}(U,\otimes)\cong C_2,
}
\]

generated by

\[
(b\ c)(u\ v).
\]

## 5. Exact automorphism group of the joint one-sorted structure

The `\oplus` table fixes both `a` and `u`.

The only nontrivial automorphism of the `\otimes` reduct would swap

\[
u\leftrightarrow v.
\]

This is incompatible with the requirement from `\oplus` that `u` remain fixed.

Hence the nontrivial `\otimes` automorphism does not extend to the joint structure. Once it is removed, `b,c,v` are all forced by the `\otimes` equations.

Therefore

\[
\boxed{
\operatorname{Aut}(U,\oplus,\otimes)=1.
}
\]

So JFS-3 survives complete erasure of the active/output typing.

## 6. One-sorted value-erasure audit

Let

\[
D_\oplus(x,y)\iff \operatorname{Def}(x\oplus y),
\qquad
D_\otimes(x,y)\iff \operatorname{Def}(x\otimes y).
\]

On the full universe `U`, the joint definedness reduct has:

- one distinguished loop point `a` from `D_\oplus`;
- an unordered two-point loop set `{b,c}` from `D_\otimes`;
- two completely isolated points `{u,v}`.

Hence

\[
\boxed{
\operatorname{Aut}(U,D_\oplus,D_\otimes)
\cong C_2\times C_2,
}
\]

with independent swaps

\[
(b\ c),
\qquad
(u\ v).
\]

### Erase only the `\oplus` values

Keep `D_\oplus` and full `\otimes`. The simultaneous swap

\[
(b\ c)(u\ v)
\]

survives, so

\[
\boxed{
\operatorname{Aut}(U,D_\oplus,\otimes)
\cong C_2.
}
\]

### Erase only the `\otimes` values

Keep full `\oplus` and `D_\otimes`. The swap

\[
(b\ c)
\]

survives while `a,u` are fixed by `\oplus`; the remaining point `v` is then fixed. Thus

\[
\boxed{
\operatorname{Aut}(U,\oplus,D_\otimes)
\cong C_2.
}
\]

### Restore both value layers

\[
\boxed{
C_2\times C_2
\longrightarrow
C_2
\longrightarrow
1.
}
\]

In either single-value-erasure direction, joint rigidity is lost. This is a strong one-sorted confirmation that both operation-value layers participate in the synchronization mechanism.

## 7. Definability without named sorts

The one-sorted joint structure internally distinguishes all five elements.

- `a` is the unique point with a defined `\oplus` self-product.
- `u=a\oplus a`.
- Among the two points having defined `\otimes` self-products, `b` is the unique one whose `\otimes` square equals `u`:

\[
B(x)\iff
\operatorname{Def}(x\otimes x)
\land
x\otimes x=a\oplus a.
\]

- `c` is the other point with a defined `\otimes` square.
- `v=c\otimes c`.

Thus no external predicate separating active points from outputs is required in the joint witness.

## 8. Association spectra and commutation

On the full one-sorted universe, every defined operation value is terminal and has no defined continuation as an argument. Hence for both operations every twice-nested product is undefined.

Therefore on `U^3`,

\[
\boxed{
(EQ,NEQ,LEFT,RIGHT,NONE)
=(0,0,0,0,125)
}
\]

for each reduct.

The commutation loci are exactly the defined diagonal cells:

\[
\operatorname{Comm}_\oplus=\{(a,a)\},
\]

\[
\operatorname{Comm}_\otimes=\{(b,b),(c,c)\}.
\]

## 9. Arithmetic Leakage firewall

The one-sorted witness remains below AL0.

There is no externally indexed family, no path, no total order, no successor, no betweenness, no EqGap, and no addition or multiplication graph. The five elements are distinguished only by three isolated operation equations and cross-operation equality of one output value.

Hence

\[
\boxed{
\text{one-sorted JFS-3: Arithmetic Leakage NONE / below AL0.}
}
\]

## 10. What the audit repairs

The typed theorem remains the clean general theorem because it gives a direct tagged-fiber stabilizer formula.

However, the prior caveat that JFS-3 itself might fail without type separation is now closed:

\[
\boxed{
\text{JFS-3 is intrinsically one-sorted.}
}
\]

The automorphism groups change after type erasure,

\[
C_2,C_2,1
\quad\leadsto\quad
S_3,C_2,1,
\]

but the balanced requirement survives and the joint structure remains rigid.

## 11. Remaining hostile question

What is **not** yet proved is a general one-sorted Lift-Compatibility theorem for arbitrary families, because in general active arguments, used outputs, unused elements, and outputs of different operations can mix in ways absent from this witness.

The next abstract step should therefore identify sufficient intrinsic role predicates under which the typed theorem descends to one-sorted structures, rather than claiming unrestricted one-sorted equivalence.
