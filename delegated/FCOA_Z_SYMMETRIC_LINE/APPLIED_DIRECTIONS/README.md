# FCOA-Z — Applied Research Directorate

**Commander Sol:** programme director  
**Date:** 2026-08-30  
**Status:** ACTIVE / EXPLORATORY / NO PHYSICAL IDENTIFICATION CLAIMED

## Mission

Test whether the mathematical mechanism discovered in FCOA-Z — one fixed partial operation acquiring different local laws after a one-sided carrier is completed to a symmetric two-sided axis — has serious analogues or useful models in physics and adjacent domains.

The goal is not to search for confirmations. Every direction has permission to return a negative verdict.

The programme distinguishes:

1. **analogy** — similar formal pattern;
2. **representation** — a faithful map between structures;
3. **model** — FCOA-Z reproduces a mathematically specified subsystem;
4. **physical claim** — requires independent empirical/physical justification and is out of scope until levels 1–3 are passed.

## Scientific directors

### SOL-GRADED — Graded algebra / Lie superalgebras / SUSY

Question: can FCOA sign-sector spectra be represented as a position-generated analogue of a grading-dependent bracket law?

Key caution: for the supercommutator

\[
[a,b]_s=ab-(-1)^{|a||b|}ba,
\]

odd–odd gives an anticommutator/symmetric graded bracket, while if at least one argument is even the formula is the ordinary commutator. Do not use the reversed folk description.

### SOL-TOPO — Anyons / fusion categories / topological memory

Question: can FCOA terminal-output channels and mixed-sign cells model the distinction between braiding memory and fusion outcomes?

Key caution: non-Abelian anyon fusion generally has multiple channels. Anyon/dual-anyon has a vacuum channel, but “opposite sign automatically makes the interaction trivial/commutative” is not a valid general statement.

### SOL-LOCALITY — AQFT / microcausality / geometry-conditioned commutation

Question: is the cleanest physical analogue of FCOA local-law differentiation the Haag–Kastler principle that observables in spacelike-separated regions commute although the global observable algebra is noncommutative?

This is currently the strongest direct physical analogy to the slogan:

\[
\text{geometry determines where an algebraic compatibility law holds}.
\]

### SOL-QFIELD — Pauli / particle–antiparticle / channel conversion

Question: can the FCOA distinction between carrier-preserving interactions and transverse output-fiber events be compared rigorously with field-theoretic channel conversion such as fermion–antifermion annihilation?

Key caution: Pauli exclusion is exchange antisymmetry of identical fermions, not noncommutativity of a binary operation; electrons and positrons are both fermionic excitations; annihilation into photons does not by itself imply that an operation became commutative.

## Shared deliverables

Each scientific director must produce:

1. exact source definitions from the target field;
2. a correspondence dictionary to FCOA objects;
3. one positive structural match;
4. one obstruction/counterexample;
5. a minimal toy model if the match survives;
6. a verdict: `ANALOGY ONLY`, `FORMAL EMBEDDING`, `MODEL CANDIDATE`, or `REJECT`;
7. a publication recommendation independent of the core FCOA-Z paper.

## Non-negotiable anti-overclaim rule

No direction may identify:

- FCOA signs with physical charge,
- FCOA reflection with CPT,
- FCOA mixed cells with annihilation,
- FCOA output fibers with photons/fusion channels,
- FCOA commutation spectra with quantum statistics,

unless an explicit mathematical mapping is constructed and audited.

The applied programme exists to test these possibilities, not assume them.
