## 1. Main result

Let

\[
M=(X^+\times X^-)\cup(X^-\times X^+)
\]

be the mixed relation, and let locality require

\[
L_{\pm}(x,y)\Longrightarrow \mathcal C(x,y)=EQ.
\]

The second SOL-LOCALITY strike asked whether locality, reflection, finite-window coherence, radial structure, or automorphism data can select one canonical mixed-value law.

The answer is negative.

## 2. Unique depth-blind base-valued law

Call a mixed generator relation-only if it sees only that \((x,y)\in M\), not the endpoint depths or identities.

If

\[
F:M\to X
\]

is relation-only and reflection-equivariant, then it is constant, say \(F(x,y)=c\). Reflection equivariance gives \(c=\nu c\). The completed FCOA axis has a unique reflection-fixed base point, namely \(x_0\). Hence

\[
\boxed{F(x,y)=x_0.}
\]

Thus the unique relation-only, base-valued, reflection-equivariant locality law is the **root bridge**

\[
\boxed{x\oplus_{BR}y=x_0\qquad((x,y)\in M).}
\]

It is conservative, mixed-commutative, one-dimensional, and finite-window coherent.

## 3. Unique depth-blind singleton-terminal law

The central branch already constructed `B0`, with one fresh reflection-fixed terminal event \(E_{cross}\):

\[
\boxed{x\oplus_{B0}y=E_{cross}\qquad((x,y)\in M).}
\]

Once the output sort is fixed to the singleton \(\{E_{cross}\}\), this law is unique.

## 4. Output-Sort Obstruction Theorem

`BR` and `B0` satisfy the same locality-level data:

- same mixed domain \(M\);
- same mixed commutation status `EQ`;
- same reflection equivariance;
- same legacy exactness;
- same finite-window coherence;
- same residual branch-swap symmetry.

But they are not the same typed FCOA realization:

\[
\operatorname{im}(BR|_M)\subseteq X,
\qquad
\operatorname{im}(B0|_M)\subseteq E_{terminal}.
\]

Therefore

\[
\boxed{\text{locality does not determine whether a mixed interaction returns to the base line or terminates in an output fiber}.}
\]

This is the first exact selector obstruction.

## 5. Locality-shadow non-reconstruction

Erase the actual mixed output values and retain only:

1. the old FCOA carrier/legacy cells;
2. which mixed pairs are defined;
3. their commutation status;
4. the locality relation.

Call this shadow \(\mathcal S_{LC}\). Then

\[
\boxed{\mathcal S_{LC}(BR)=\mathcal S_{LC}(B0)}
\]

while the typed source structures are nonisomorphic. Hence no reconstruction rule from the bare locality/commutation shadow can recover every admissible FCOA mixed law uniquely.

## 6. Radial naturality does not select the v0.1 family

Let \(N_j\) be the base-valued locality-compatible family from SOL-LOCALITY v0.1, obtained by choosing the nearer mixed endpoint and then applying \(j\) clamped radial contractions.

For every mixed pair whose two depths are at least two,

\[
\boxed{\rho(N_j(x,y))=N_j(\rho x,\rho y)}.
\]

Thus every \(N_j\) has the same interior radial naturality. They are nevertheless pairwise distinct.

So even adding:

- base closure;
- reflection equivariance;
- radial non-expansion;
- output on the nearer radial chain;
- interior radial naturality;
- finite-window coherence;

still does not produce uniqueness.

## 7. Automorphism data does not select

The hostile-audited signed `oplus` baseline has finite-window automorphism group \(C_2\), generated by reflection. Every reflection-equivariant locality extension among

\[
BR,\quad B0,\quad N_j
\]

has the same finite-window automorphism group \(C_2\): expansions cannot create new old-carrier automorphisms, and reflection survives in every case.

Therefore rigidity/automorphism-group size is not a locality selector.

## 8. Association distinguishes regimes but does not canonize one

`BR` re-enters immediately and creates explicit alternating nonassociativity. For example,

\[
(x_a\oplus_{BR}x_{-b})\oplus x_a=x_a,
\]

whereas

\[
x_a\oplus_{BR}(x_{-b}\oplus_{BR}x_a)=x_a\oplus x_0=\rho(x_a)\ne x_a.
\]

By contrast, `B0` returns a terminal event and creates an association-definedness wall: the mixed result cannot re-enter the baseline binary operation.

The v0.1 laws \(N_j\) are also nonassociative. For example,

\[
(x_{j+2}\oplus x_0)\oplus_{N_j}x_{-(j+3)}=x_1,
\]

while

\[
x_{j+2}\oplus_{N_j}(x_0\oplus x_{-(j+3)})=x_2.
\]

Hence association detects the output/re-entry regime, but locality supplies no reason to prefer one regime.

Global associativity is not a valid tie-breaker: the central Associative Saturation Collapse theorem shows that forcing a semigroup realization of the legacy root cells collapses all base coordinates.

## 9. Locality-Only Selector No-Go

No selector depending only on

1. branch-separation locality;
2. mixed definedness;
3. mixed commutation;
4. reflection equivariance;
5. finite-window coherence;
6. residual finite-window automorphism group

can select a unique conservative FCOA-Z mixed realization.

`BR` and `B0` agree on all six and are nonisomorphic typed extensions.

Even within the base-valued depth-sensitive class, adding radial naturality and radial non-expansion leaves the infinite family \(N_j\).

Therefore

\[
\boxed{\text{canonicality requires an extra typing/information/re-entry axiom, not a stronger locality axiom}.}
\]

## 10. Selector trichotomy

The mixed problem now splits into three regimes.

### A. Relation-only + base return

Unique:

\[
\boxed{BR(x,y)=x_0.}
\]

### B. Relation-only + singleton terminal event

Unique:

\[
\boxed{B0(x,y)=E_{cross}.}
\]

### C. Radial-information retention

Nonunique: infinitely many \(N_j\), plus richer bridge-indexed terminal laws such as `B1`.

Thus the canonicality problem first splits by **information policy and output sort**, before any physical interpretation.
