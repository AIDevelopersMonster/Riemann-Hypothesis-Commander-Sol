## 1. Problem after the Shadow-Reconstruction publication

The published Shadow-Reconstruction layer proves two facts that at first look contradictory:

1. the enriched base shadow
   \[
   (I,U,V),
   \qquad I=M_{fin}(\mathbb Z,K),
   \]
   reconstructs the rooted signed carrier line;
2. the same base shadow does not, by itself, recover primitive-operation provenance, the distinction between terminal-valued and `UNDEF` cells, or terminal attachment.

The previous reconstruction ladder therefore treated full terminal incidence as an additional information layer.

For the unrestricted class of partial expansions this is correct. For the **canonical signed-M0 reflection-closure class**, however, it is too pessimistic.

The central result of this note is:

\[
\boxed{
\text{the infinite signed-M0 operation table is generated by a finite law schema plus a terminal lift profile.}
}
\]

Thus the true unresolved information is not an arbitrary infinite incidence table. It is the regularity, or lack of regularity, of the `share/split` choices on terminal reflection orbits.

## 3. Seven active signed-M0 schema families

The complete base-base table of the canonical minimal signed M0 is generated by seven active law families together with a default-undefined rule.

### `oplus`

For every nonroot \(x\):

\[
x_0\oplus x=x.
\tag{3.1}
\]

For every nonroot \(x\):

\[
x\oplus x_0=\rho(x).
\tag{3.2}
\]

For every \(n\ge1\) and branch \(\sigma\):

\[
x_n^\sigma\oplus x_n^\sigma
=E_{+,n}^{\sigma}.
\tag{3.3}
\]

All remaining base-base `oplus` cells are undefined.

### `otimes`

For every \(n\ge1\) and branch \(\sigma\):

\[
x_0\otimes x_n^\sigma=x_0.
\tag{3.4}
\]

For every \(n\ge2\):

\[
x_n^\sigma\otimes x_0
=E_{*,n}^{\sigma}.
\tag{3.5}
\]

For every \(n\ge2\):

\[
x_1^\sigma\otimes x_n^\sigma
=x_n^\sigma\otimes x_1^\sigma
=x_n^\sigma.
\tag{3.6}
\]

For every \(n\ge2\):

\[
x_n^\sigma\otimes x_n^\sigma
=E_{\times,n}^{\sigma}.
\tag{3.7}
\]

All remaining base-base `otimes` cells are undefined, including

\[
x_1^\sigma\otimes x_0,
\qquad
x_1^\sigma\otimes x_1^\sigma,
\]

all distinct generic same-branch pairs, and all genuinely mixed-sign pairs.

Equations (3.1)–(3.7) are a finite **schema**: they generate infinitely many cells by iteration of the already reconstructed one-dimensional shift.

No claim of first-order definability is made here. The statement is reconstruction by finite recursive schema.

## 5. Orbitwise canonical terminal lifts

We now enlarge the two global baselines `ZM0-share` and `ZM0-split` to the maximal orbitwise class that still makes no exotic identifications.

### Definition 5.1 — orbitwise canonical lift

For each \(q\in\mathcal I\), independently choose one of two lift types.

#### Shared lift

Retain one output \(E_q\) and set

\[
\nu_E(E_q)=E_q.
\tag{5.1}
\]

The positive and negative mirror source cells use the same terminal value.

#### Split lift

Retain \(E_q^+\), introduce one fresh mate \(E_q^-\), and set

\[
\nu_E(E_q^+)=E_q^-,
\qquad
\nu_E(E_q^-)=E_q^+.
\tag{5.2}
\]

The positive and negative mirror source cells use the two distinct values.

We impose:

1. no identification between different indices \(q\ne q'\);
2. no terminal output re-entry as an operation argument;
3. no additional terminal relations beyond channel typing and reflection.

This defines the **orbitwise canonical lift class**.

### Definition 5.2 — terminal lift profile

A terminal lift profile is a function

\[
\epsilon:\mathcal I\to\{0,1\},
\tag{5.3}
\]

where

\[
\epsilon(q)=0
\iff q\text{ is shared},
\]

\[
\epsilon(q)=1
\iff q\text{ is split}.
\]

Let \(F_\epsilon\) denote the signed-M0 expansion synthesized from (3.1)–(3.7) and profile \(\epsilon\).

## 6. Terminal Lift Classification Theorem

### Theorem 6.1

The isomorphism classes in the orbitwise canonical lift class are in bijection with

\[
\boxed{\{0,1\}^{\mathcal I}.}
\tag{6.1}
\]

Equivalently,

\[
\boxed{
F_\epsilon\cong F_\eta
\iff
\epsilon=\eta.
}
\tag{6.2}
\]

### Proof

Existence for every profile is immediate. For each \(q\), use either (5.1) or (5.2), then assign the negative mirror terminal cell according to the chosen involution. Since terminal elements do not re-enter the operations, choices at distinct \(q\) do not interact.

Now suppose

\[
\Phi:F_\epsilon\to F_\eta
\]

is an isomorphism of typed signed-M0 structures.

The primitive `oplus` reduct structurally determines the root and radial depth: right multiplication by the root gives the two rooted radial chains. Therefore \(\Phi\) preserves each depth \(n\), though it may exchange the two branches simultaneously.

The operation symbol and terminal channel type determine whether a given terminal-producing orbit is of type \(+\), \(*\), or \(\times\). Hence every index

\[
q=(\alpha,n)
\]

is preserved.

At that orbit, the attached terminal reflection structure has either:

- one reflection-fixed element, if \(\epsilon(q)=0\); or
- a nontrivial reflection two-cycle, if \(\epsilon(q)=1\).

Fixed-point versus two-cycle type is invariant under isomorphism of involutive terminal fibers. Therefore

\[
\epsilon(q)=\eta(q)
\]

for every \(q\in\mathcal I\). Thus \(\epsilon=\eta\).

The converse is tautological from the construction. \(\square\)

## 7. Continuum Fibre Theorem

Let \(\mathscr B\) be the base-only shadow that retains the signed base carrier, all base-to-base primitive translation components, \(T\), and \(\nu\), while erasing terminal outputs and terminal-valued components.

### Theorem 7.1

For all profiles \(\epsilon,\eta\),

\[
\boxed{
\mathscr B(F_\epsilon)=\mathscr B(F_\eta).
}
\tag{7.1}
\]

But the fibre over this common shadow contains exactly

\[
\boxed{2^{\aleph_0}}
\tag{7.2}
\]

pairwise nonisomorphic orbitwise canonical signed-M0 expansions.

### Proof

The base-valued cells (3.1), (3.2), (3.4), and (3.6) are independent of \(\epsilon\). The remaining active cells are terminal-valued and are deleted by \(\mathscr B\). Hence every profile has the same base shadow.

By Theorem 6.1, isomorphism classes are indexed exactly by binary functions on the countably infinite set \(\mathcal I\). Therefore their number is

\[
|\{0,1\}^{\mathcal I}|=2^{\aleph_0}.
\]

\(\square\)

### Consequence 7.2 — no finite-tag reconstruction in the unrestricted orbitwise class

No scheme that augments the common base shadow by only an arbitrary finite string over a fixed finite alphabet can identify every orbitwise canonical lift.

### Proof

The set of all finite strings over a fixed finite alphabet is countable, whereas the fibre in (7.2) has cardinality \(2^{\aleph_0}\). No injective coding exists. \(\square\)

This is an exact obstruction. It does not rely on computational complexity assumptions.

## 8. Regularity collapses the reconstruction cost

The continuum ambiguity comes entirely from allowing the lift choice to fluctuate independently with radial depth and channel.

Impose regularity and the fibre collapses sharply.

### Definition 8.1 — channel-uniform profile

A profile is channel-uniform if there exist

\[
b_+,b_*,b_\times\in\{0,1\}
\]

such that

\[
\epsilon(\alpha,n)=b_\alpha
\]

for every allowed depth \(n\).

### Theorem 8.2 — Eight-Lift Theorem

The channel-uniform class contains exactly

\[
\boxed{2^3=8}
\tag{8.1}
\]

pairwise nonisomorphic signed-M0 lifts over the same base shadow.

### Proof

There are three independent typed terminal channel families and two uniform choices for each. Distinct triples

\[
(b_+,b_*,b_\times)
\]

differ in fixed-point/two-cycle type on at least one structurally distinguished terminal channel and hence are nonisomorphic. \(\square\)

Thus three binary selectors are sufficient and, among fixed-length binary labels, necessary to distinguish all channel-uniform lifts.

### Definition 8.3 — globally uniform profile

A profile is globally uniform if

\[
b_+=b_*=b_\times=b.
\]

### Corollary 8.4 — Two-Lift Theorem

The globally uniform class contains exactly the two familiar baselines:

\[
\boxed{ZM0\text{-share},\qquad ZM0\text{-split}.}
\tag{8.2}
\]

One binary selector distinguishes them.

No other cell or output relation remains unspecified. Therefore the synthesized expansion is unique up to renaming of freshly created terminal elements, i.e. up to typed isomorphism. \(\square\)

## 10. Relative Provenance Recovery

The published provenance no-go says that the bare generated classical algebra does not remember whether certain operators were primitive `oplus` translations or derived operators.

That statement remains correct.

However, once the source class is restricted by the audited finite signed-M0 schema, a different statement holds.

### Theorem 10.1 — Relative Reconstruction Injectivity

Fix a terminal profile \(\epsilon\), and let \(\mathcal C_{M0,\epsilon}\) be the class of signed structures satisfying the reconstructed line axioms and the fixed schema \(\Sigma_{M0}\) with profile \(\epsilon\).

If

\[
F,G\in\mathcal C_{M0,\epsilon}
\]

and

\[
\mathscr B(F)\cong\mathscr B(G),
\]

then

\[
\boxed{F\cong G.}
\tag{10.1}
\]

### Proof

The common enriched base shadow reconstructs the signed line. The fixed schema and fixed profile then synthesize a unique expansion by Theorem 9.1. Hence both \(F\) and \(G\) are isomorphic to that synthesis. \(\square\)

### Interpretation

Primitive provenance is therefore:

- **not absolutely recoverable** from the bare generated algebra;
- **relatively reconstructible** after the admissible source theory \(\Sigma_{M0}\) is supplied.

This is not a contradiction. The schema is extra information not contained in the bare shadow.

If one insists on recovering the original terminal elements with their literal identities from an erased base shadow, the information is lost.
