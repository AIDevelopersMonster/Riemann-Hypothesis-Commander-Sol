## Abstract

We continue the one-dimensional FCOA-Z programme after the published shadow-reconstruction result. The previous layer showed that the enriched classical shadow \((M_{\mathrm{fin}}(\mathbb Z,K),U,V)\) reconstructs the rooted signed carrier line while forgetting primitive-operation provenance, the distinction between undefined and terminal-valued cells, and terminal attachment. Here we classify that erased terminal layer for the canonical signed-M0 reflection closure. The terminal-producing reflection orbits form a countable index set \(\mathcal I\), and every orbit independently admits a shared or split reflection lift. The resulting canonical expansion fibre over the common base shadow has cardinality \(2^{\aleph_0}\). Nevertheless, the full signed-M0 operation table is generated by a finite seven-family schema together with the terminal lift profile. Under channel-uniformity the continuum ambiguity collapses to eight profiles. Equality coupling among the three terminal channels is classified by connected components of a finite channel graph, yielding the exact ambiguity ladder \(8\to4\to2\), while an additional anchor yields \(1\). We then prove an exact finite-window law: each split terminal orbit costs exactly one new reflected output and restores exactly one unit of branch-sensitive terminal memory. Natural selectors conflict: minimal extension cost and \(\otimes\)-rigidity favor `share`, maximal branch memory and faithful terminal reflection favor `split`, while full \((\oplus,\otimes)\) automorphism rigidity ties them. The result is a quantitative reconstruction theory for a terminal layer erased by classicalization, entirely within one spatial dimension.

## 2. Finite signed-M0 schema

Write

\[
x_n^+=T^n x_0,\qquad x_n^-=T^{-n}x_0\qquad(n\ge1),
\]

and

\[
\rho(x_n^\sigma)=
\begin{cases}
x_0,&n=1,\\
x_{n-1}^\sigma,&n\ge2,
\end{cases}
\qquad \sigma\in\{+,-\}.
\tag{2.1}
\]

The canonical minimal signed-M0 table is generated by seven active law families:

\[
x_0\oplus x=x\qquad(x\ne x_0),
\tag{2.2}
\]

\[
x\oplus x_0=\rho(x)\qquad(x\ne x_0),
\tag{2.3}
\]

\[
x_n^\sigma\oplus x_n^\sigma=E_{+,n}^{\sigma}\qquad(n\ge1),
\tag{2.4}
\]

\[
x_0\otimes x_n^\sigma=x_0\qquad(n\ge1),
\tag{2.5}
\]

\[
x_n^\sigma\otimes x_0=E_{*,n}^{\sigma}\qquad(n\ge2),
\tag{2.6}
\]

\[
x_1^\sigma\otimes x_n^\sigma=x_n^\sigma\otimes x_1^\sigma=x_n^\sigma\qquad(n\ge2),
\tag{2.7}
\]

\[
x_n^\sigma\otimes x_n^\sigma=E_{\times,n}^{\sigma}\qquad(n\ge2).
\tag{2.8}
\]

Every unlisted base-base cell is undefined. In particular the \(n=1\) exceptional \(\otimes\) cells and all genuinely mixed-sign cells remain undefined.

### Proposition 2.1 — Finite-Schema Synthesis

Once the signed line is reconstructed, equations (2.2)-(2.8), the default-undefined rule, and a terminal reflection profile determine the full canonical signed-M0 expansion up to typed isomorphism.

### Proof

The reconstructed shift produces every radial coordinate. The seven schemas determine every base-valued cell and every terminal-producing source orbit. The default rule determines all remaining `UNDEF` cells. The terminal profile determines how each positive terminal value is reflected. No operation cell remains free. \(\square\)

## 3. Terminal lift profiles

The terminal-producing positive reflection orbits are indexed by

\[
\mathcal I=\mathcal I_+\sqcup\mathcal I_*\sqcup\mathcal I_\times,
\tag{3.1}
\]

where

\[
\mathcal I_+=\{(+,n):n\ge1\},
\quad
\mathcal I_*=\{(*,n):n\ge2\},
\quad
\mathcal I_\times=\{(\times,n):n\ge2\}.
\tag{3.2}
\]

At each index \(q\in\mathcal I\), an orbitwise canonical lift is either:

- `share`: one reflection-fixed terminal output;
- `split`: two distinct terminal outputs exchanged by reflection.

Different indices are not identified, terminal outputs do not re-enter primitive operations, and no extra cross-terminal relation is added.

A terminal lift profile is therefore

\[
\epsilon:\mathcal I\to\{0,1\},
\tag{3.3}
\]

with \(0=\) share and \(1=\) split.

### Theorem 3.1 — Terminal Lift Classification

\[
\boxed{F_\epsilon\cong F_\eta\iff \epsilon=\eta.}
\tag{3.4}
\]

### Proof

The \(\oplus\) structure fixes root and radial depth up to global branch reflection. The operation/source pattern distinguishes the three terminal channel types. At fixed channel and depth, a shared fibre is a reflection-fixed point while a split fibre is a nontrivial two-cycle. This distinction is invariant under typed isomorphism. Hence every profile bit is preserved. \(\square\)

### Corollary 3.2 — Continuum Fibre

Since \(\mathcal I\) is countably infinite, the common base shadow has exactly

\[
\boxed{2^{\aleph_0}}
\tag{3.5}

pairwise nonisomorphic orbitwise canonical terminal expansions.

## 4. Terminal opacity and relative reconstruction

Let \(\mathscr B(F)\) erase terminal outputs and terminal-valued components while retaining the signed base carrier, \(T\), \(\nu\), and every base-to-base primitive component.

### Theorem 4.1 — Terminal Opacity

For all profiles \(\epsilon,\eta\),

\[
\boxed{\mathscr B(F_\epsilon)=\mathscr B(F_\eta).}
\tag{4.1}
\]

### Proof

Only terminal fibres and terminal-valued components depend on the profile. Every retained base datum is identical. \(\square\)

Thus no statement in the base signature can recover even one terminal profile bit.

### Theorem 4.2 — Relative Reconstruction

Fix the signed-M0 schema and a profile \(\epsilon\). Then \((I,U,V)\) determines \(F_\epsilon\) up to typed isomorphism.

### Proof

The published theorem reconstructs the signed line from \((I,U,V)\). Proposition 2.1 then synthesizes the unique expansion with the fixed schema and profile. \(\square\)

Primitive provenance is therefore not absolutely recoverable from the bare generated algebra, but becomes relatively reconstructible after the admissible source theory is supplied.

Every binary profile \(\epsilon:\mathcal I\to\{0,1\}\) is compatible with the current terminal-opacity axioms.

## 6. Finite channel coupling

Let

\[
C=\{+,*,\times\}
\]

and let \(G=(C,E)\) be a finite simple graph. Each edge \(\{\alpha,\beta\}\) imposes

\[
b_\alpha=b_\beta.
\tag{6.1}
\]

### Theorem 6.1 — Connected-Component Classification

A profile satisfies all equality constraints of \(G\) iff it is constant on each connected component. Consequently

\[
\boxed{N(G)=2^{c(G)}}.
\tag{6.2}
\]

### Proof

Equalities propagate along paths, and any componentwise constant profile satisfies all edge equalities. Each component contributes one free bit. \(\square\)

For the three FCOA-Z terminal channels,

\[
\boxed{8\xrightarrow{1\text{ equality}}4\xrightarrow{1\text{ more equality}}2.}
\tag{6.3}
\]

Two independent equality constraints are necessary and sufficient to force global uniformity.

Pure equality constraints cannot select global share over global split: bitwise complement preserves every equality. One additional unary anchor fixes the common bit. Within this explicitly defined equality-plus-anchor language with unit costs, the minimum cost of a unique three-channel profile is therefore \(3\).

## 7. Exact terminal cost-memory duality

For

\[
W_N=\{x_0\}\cup\{x_n^+,x_n^-:1\le n\le N\},
\]

the number of visible terminal-producing orbits is

\[
Q_N=3N-2\qquad(N\ge2),
\tag{7.1}
\]

with \(Q_1=1\).

Let \(C_N(\epsilon)\) be the number of new reflected terminal outputs required beyond the positive legacy outputs. Let \(M_N(\epsilon)\) be the number of visible mirror orbits whose positive and negative source cells receive distinct terminal values.

Each shared orbit contributes \((0,0)\); each split orbit contributes \((1,1)\).

### Theorem 7.1 — Cost-Memory Duality

For every profile and finite window,

\[
\boxed{C_N(\epsilon)=M_N(\epsilon).}
\tag{7.2}
\]

### Proof

Both sides equal the number of visible split orbits. \(\square\)

For a fixed window the all-share visible restriction uniquely minimizes cost, while the all-split visible restriction uniquely maximizes branch memory. Globally, share is the unique profile that minimizes cost simultaneously on every finite window, and split is the unique profile that maximizes branch memory simultaneously on every finite window.

Plain infinite cardinality is not a selector because

\[
|E_{share}|=|E_{split}|=\aleph_0.
\tag{7.3}
\]

For a fixed window the exact attainable aggregate set is

\[
\boxed{\{(C_N,M_N)=(k,k):0\le k\le Q_N\}.}
\tag{7.4}
\]

Thus every additional unit of branch-sensitive terminal memory costs exactly one additional reflected output in the canonical orbitwise class.

## 8. Share/split selector audit

The two globally uniform endpoints are selected differently by different structural criteria.

The already audited finite-window \(\otimes\) automorphism groups are

\[
\operatorname{Aut}(W_N,\otimes)_{split}\cong S_{N-1}\wr C_2,
\tag{8.1}
\]

\[
\operatorname{Aut}(W_N,\otimes)_{share}\cong S_{N-1}\times C_2.
\tag{8.2}
\]

Hence for \(N\ge3\), share is the more rigid \(\otimes\) reduct. But with both legacy operations retained,

\[
\operatorname{Aut}(W_N,\oplus,\otimes)\cong C_2
\tag{8.3}
\]

for both variants, so full-operation rigidity is a nonselector.

Terminal reflection is trivial on global share and nontrivial on global split. Since the acting group is \(C_2\), the split terminal action is faithful.

### Theorem 8.1 — Selector Conflict

Among the audited criteria:

1. simultaneous all-window extension-cost minimization selects `share`;
2. simultaneous all-window branch-memory maximization selects `split`;
3. \(\otimes\)-rigidity for \(N\ge3\) selects `share`;
4. full \((\oplus,\otimes)\)-rigidity ties the variants;
5. faithful terminal reflection selects `split`.

Therefore the current source does not provide a criterion-independent canonical winner.

This theorem does not rule out a future invariant; it only proves conflict within the present natural selector family.

## 11. Conclusion

Classicalization in FCOA-Z erases a terminal layer that is large but highly structured. Without regularity, one common base shadow supports continuum many canonical terminal expansions. Yet the primitive operation table itself is finitely schematized, so reconstruction reduces to a terminal profile rather than an arbitrary infinite incidence table. Channel uniformity compresses the ambiguity to three bits. Equality coupling reduces those bits according to connected components of a finite channel graph, while equality alone cannot choose between global share and global split. The residual choice has an exact resource interpretation: each split orbit costs one new reflected output and restores one unit of branch-sensitive terminal memory. Natural structural selectors then disagree on which endpoint is preferable.

This yields a quantitative hierarchy of erased, regularized, coupled, and selectively reconstructed terminal information over a fixed one-dimensional carrier.
