## 1. Aim

The previous Shadow Ladder package proved that specific FCOA-Z structures produce the classical shadows

\[
\mathbb Z,
\qquad
D_\infty,
\qquad
\mathbb Z_{ring},
\qquad
K[t,t^{-1}],
\qquad
K[D_\infty].
\]

This note asks the broader coverage question:

\[
\boxed{
\text{How much of ordinary classical algebra can occur as a translation/operator shadow of a genuinely partial FCOA-style source?}
}
\]

The answer is already wide:

1. every semigroup occurs exactly as a translation-semigroup shadow;
2. every small category occurs exactly as a translation-category shadow;
3. therefore every category algebra occurs exactly as an associative algebra shadow;
4. in particular this includes group algebras, monoid algebras, path algebras, finite incidence algebras, and full matrix algebras;
5. every unital associative algebra over a field is a quotient of a free associative algebra that itself occurs as an exact translation-category shadow.

The source operation used for these realizations remains highly partial and role-sensitive; classical associativity appears only after composition of translations.

None of items 1–5 is claimed as a new classical representation theorem. The FCOA research content is the coexistence of these coverage results with the already proved direct-associativization collapse and the resulting intrinsic-versus-shadow distinction.

## 2. Exact semigroup realization

Let \(S\) be an arbitrary semigroup.

Let \(S^1\) denote \(S\) with an identity adjoined if necessary.

Create two disjoint sorts:

\[
X_S:=S^1
\]

(the **state sort**) and

\[
M_S:=\{\bar a:a\in S\}
\]

(the **marker sort**).

Define one partial binary operation \(\star_S\) only on marker-state pairs:

\[
\boxed{
\bar a\star_S x=ax
}
\qquad
(a\in S,\ x\in S^1).
\tag{2.1}
\]

All cells outside

\[
M_S\times X_S
\]

are undefined.

For \(a\in S\), let

\[
L_a:X_S\to X_S,
\qquad
L_a(x)=\bar a\star_S x=ax.
\tag{2.2}
\]

### Theorem 2.1 — Exact Semigroup Shadow Realization

The map

\[
\lambda:S\to\operatorname{End}(X_S),
\qquad
\lambda(a)=L_a
\]

is an injective semigroup homomorphism. Its image is precisely the translation semigroup generated by the marker translations. Hence

\[
\boxed{
\langle L_a:a\in S\rangle\cong S.
}
\tag{2.3}
\]

### Proof

For \(a,b\in S\) and \(x\in S^1\),

\[
(L_a\circ L_b)(x)
=a(bx)
=(ab)x
=L_{ab}(x).
\tag{2.4}
\]

Thus

\[
L_a\circ L_b=L_{ab}.
\]

So \(\lambda\) is a homomorphism.

If \(L_a=L_b\), evaluate both maps at the identity element \(1\in S^1\):

\[
a=L_a(1)=L_b(1)=b.
\]

Hence \(\lambda\) is injective.

Since every composition of marker translations reduces by (2.4) to one marker translation, the generated translation semigroup is exactly \(\lambda(S)\). \(\square\)

## 3. The source is not a semigroup law in disguise

The primitive partial operation \(\star_S\) is not total on one carrier. It is typed and role-sensitive:

\[
M_S\times X_S\to X_S,
\]

with marker-marker and state-state cells absent.

For \(a,b\in S\) and \(x\in S^1\), the right-nested term

\[
\bar a\star_S(\bar b\star_S x)
\]

is defined, but

\[
(\bar a\star_S\bar b)\star_S x
\]

is undefined already at the inner marker-marker cell.

Thus in the existing FCOA partial-association diagnostic the composable triple has status

\[
\boxed{RIGHT}
\tag{3.1}
\]

rather than `EQ`.

Yet its left-translation shadow is the associative semigroup \(S\).

Therefore

\[
\boxed{
\text{associativity of the translation shadow does not require associativity of the primitive value law.}
}
\tag{3.2}
\]

## 4. Exact category realization

Let \(\mathcal C\) be a small category.

For every object \(c\in\operatorname{Ob}(\mathcal C)\), define the tagged state sort

\[
X_c
:=
\coprod_{u\in\operatorname{Ob}(\mathcal C)}
\operatorname{Hom}_{\mathcal C}(u,c).
\tag{4.1}
\]

An element of \(X_c\) is therefore an arrow

\[
g:u\to c,
\]

with the target tag \(c\) retained.

For every arrow

\[
f:c\to d,
\]

introduce a marker \(\bar f\).

Define a partial typed operation \(\star_{\mathcal C}\) by

\[
\boxed{
\bar f\star_{\mathcal C} g=f\circ g
}
\tag{4.2}
\]

whenever

\[
g:u\to c.
\]

Thus \(\bar f\) acts on the whole state sort \(X_c\) and sends it to \(X_d\).

All marker-marker cells and all other ill-typed cells are undefined.

Let

\[
L_f:X_c\to X_d,
\qquad
L_f(g)=f\circ g.
\tag{4.3}
\]

### Theorem 4.1 — Universal Category Shadow Realization

The assignment

\[
Y_{tr}:\mathcal C\to\mathcal T(\star_{\mathcal C}),
\]

which sends

\[
c\mapsto X_c,
\qquad
f\mapsto L_f,
\]

is an isomorphism from \(\mathcal C\) onto the category generated by the marker translations.

In particular,

\[
\boxed{
\mathcal T(\star_{\mathcal C})\cong\mathcal C.
}
\tag{4.4}
\]

### Proof

For the identity arrow \(1_c:c\to c\),

\[
L_{1_c}(g)=1_c\circ g=g,
\]

so \(L_{1_c}=\operatorname{id}_{X_c}\).

For composable arrows

\[
f:c\to d,
\qquad
h:d\to e,
\]

and \(g:u\to c\),

\[
(L_h\circ L_f)(g)
=h\circ(f\circ g)
=(h\circ f)\circ g
=L_{h\circ f}(g).
\tag{4.5}
\]

Thus composition is preserved.

To prove faithfulness, suppose

\[
f,g:c\to d
\]

and

\[
L_f=L_g.
\]

The identity arrow \(1_c\) belongs to \(X_c\). Therefore

\[
f=L_f(1_c)=L_g(1_c)=g.
\tag{4.6}
\]

Hence distinct arrows induce distinct translations.

Finally every generated translation is a finite composite of some \(L_f\)'s, which by repeated use of (4.5) equals the translation associated with their categorical composite. Thus no additional arrows occur. \(\square\)

### Prior-art note

The proof is a concrete translation form of the classical Cayley/Yoneda philosophy. The fully faithful Yoneda embedding of a small category into representable set-valued functors is classical. No novelty is claimed for the existence of such faithful category representations.

## 5. Primitive partial association remains one-sided

Let

\[
f:c\to d,
\qquad
h:d\to e,
\qquad
g:u\to c.
\]

Then

\[
\bar h\star_{\mathcal C}(\bar f\star_{\mathcal C}g)
\]

is defined and equals

\[
(h\circ f)\circ g.
\]

But

\[
\bar h\star_{\mathcal C}\bar f
\]

is undefined because the second argument is a marker rather than a state.

Hence every genuinely composable length-two arrow chain gives the FCOA partial-association status

\[
\boxed{RIGHT}.
\tag{5.1}
\]

At the primitive level the construction therefore retains maximal role distinction; at the translation level it recovers ordinary associative categorical composition.

## 6. Category-algebra consequence

Let \(K\) be a field and let \(K[\mathcal C]\) denote the finite-support category algebra: the \(K\)-vector space with basis the arrows of \(\mathcal C\), with multiplication given by categorical composition for composable basis arrows and zero otherwise.

### Theorem 6.1 — Associative Category-Algebra Shadow

For every small category \(\mathcal C\),

\[
\boxed{
K[\mathcal T(\star_{\mathcal C})]
\cong
K[\mathcal C].
}
\tag{6.1}
\]

The algebra is associative. If \(\mathcal C\) has finitely many objects, it is unital with identity equal to the finite sum of the object identities.

### Proof

Theorem 4.1 gives an isomorphism of categories. Extending the induced bijection on arrows \(K\)-linearly yields a vector-space isomorphism. Because the category isomorphism preserves composability and composition, the linear extension preserves multiplication. \(\square\)

## 7. Classical families obtained exactly

Theorem 6.1 contains many ordinary algebras as exact shadows.

### 7.1 Group algebras

A group \(G\) is a one-object category. Hence

\[
\boxed{K[G]}
\]

is an exact translation-category algebra shadow.

### 7.2 Monoid algebras

Likewise every monoid algebra

\[
\boxed{K[M]}
\]

is an exact shadow.

### 7.3 Path algebras

For a quiver \(Q\), let \(FQ\) be its free category of directed paths. Then

\[
\boxed{K[FQ]=KQ,}
\tag{7.1}
\]

the ordinary path algebra of \(Q\).

Thus every path algebra is an exact translation-category shadow.

### 7.4 Matrix algebras

Let \(\mathcal P_n\) be the category with objects \(1,\ldots,n\) and exactly one arrow

\[
e_{ij}:j\to i
\]

for every ordered pair \((i,j)\).

Then

\[
e_{ij}\circ e_{jk}=e_{ik},
\]

and nonmatching pairs are noncomposable.

Sending

\[
e_{ij}\mapsto E_{ij}
\]

to the standard matrix units gives

\[
\boxed{
K[\mathcal P_n]\cong M_n(K).
}
\tag{7.2}
\]

Hence every full matrix algebra is an exact FCOA translation-category shadow.

### 7.5 Finite incidence algebras

A finite poset \(P\) defines a category with one arrow \(x\to y\) exactly when \(x\le y\). Its category algebra is the usual finite incidence algebra up to the conventional choice of multiplication orientation.

Thus finite incidence algebras also occur exactly.

## 8. Universal quotient coverage for associative algebras

Exact category-algebra shadows do not exhaust all associative algebras. However quotient coverage is universal.

Let \(A\) be a unital associative \(K\)-algebra generated by a set \(I\).

Let \(Q_I\) be the one-vertex quiver with one loop \(a_i\) for each \(i\in I\).

Its path algebra is the free associative algebra

\[
KQ_I
\cong
K\langle x_i:i\in I\rangle.
\tag{8.1}
\]

Since \(A\) is generated by the chosen elements, there is a surjective algebra homomorphism

\[
\pi:
K\langle x_i:i\in I\rangle
\twoheadrightarrow A
\]

whose kernel is the ideal of relations among those generators.

### Theorem 8.1 — Universal Associative Quotient Coverage

Every unital associative \(K\)-algebra is a quotient of an associative translation-category shadow of an FCOA-style partial source:

\[
\boxed{
A
\cong
K[\mathcal T(F_I)]/J
}
\tag{8.2}
\]

for a suitable one-vertex realization \(F_I\) and ideal \(J\).

If \(A\) is finitely generated, \(I\) may be chosen finite. If \(A\) is finitely presented, \(J\) may be chosen finitely generated as a defining ideal.

### Proof

Apply Theorem 4.1 to the free category of \(Q_I\). By Theorem 6.1 its category algebra is the free associative algebra in (8.1). Quotient by the kernel of the canonical evaluation map onto \(A\). \(\square\)

### Scope

This is an existential coverage theorem, not an intrinsic-emergence theorem. The relation ideal \(J\) may encode essentially all of the target algebra. Therefore (8.2) does not by itself show that a given algebra arises naturally from the legacy FCOA-Z rules.

Let \(F_Z\) be any audited FCOA-Z structure on the signed line.

Form the disjoint many-sorted expansion

### Proposition 9.1 — Conservative Classical-Shadow Attachment

The expansion leaves every old FCOA-Z carrier element, defined cell, undefined cell, value, reflection law, and legacy theorem unchanged, while adding a translation-category component isomorphic to \(\mathcal C\).

## 10. Universal non-reconstruction of the bare shadow

The many-to-one phenomenon is not special to `ZM0-share` and `ZM0-split`.

Fix any source \(F_{\mathcal C}\) from Theorem 4.1.

Adjoin a two-element terminal sort

\[
E=\{e_0,e_1\}
\]

which never occurs in a translation-generating operation.

Construct two expansions with the same underlying sorts and cardinalities:

1. \(F_{fix}\): an output involution \(\eta\) fixes both \(e_0,e_1\);
2. \(F_{swap}\): \(\eta\) swaps \(e_0,e_1\).

### Theorem 10.1 — Universal Shadow Non-Reconstruction

\[
\boxed{F_{fix}\not\cong F_{swap}}
\tag{10.1}
\]

as typed structures with \(\eta\), but

\[
\boxed{
\mathcal T(F_{fix})\cong
\mathcal T(F_{swap})\cong
\mathcal C.
}
\tag{10.2}
\]

Hence the bare translation-category shadow is not injective on source isomorphism classes for any target category \(\mathcal C\).

### Proof

In \(F_{fix}\), the involution \(\eta\) has two fixed points on \(E\). In \(F_{swap}\), it has none. Fixed-point count is invariant under isomorphism of structures preserving the terminal sort and involution, so the sources are nonisomorphic.

The sort \(E\) is absent from all translation-generating operation domains. Therefore the generated translation categories of the two structures are identical to that of the common base realization \(F_{\mathcal C}\). Apply Theorem 4.1. \(\square\)

### Corollary 10.2

There is no reconstruction procedure from the bare category shadow that recovers the actual richer source on any source class containing both constructions.

The FCOA translation-shadow framework has very broad **expressive coverage**:

\[
\boxed{
\text{all semigroups}
\subseteq

\tag{11.1}

\[
\boxed{
\text{all small categories}
\subseteq

\tag{11.2}
\]

\[
\boxed{
\text{all category algebras}
\subseteq
\text{exact associative shadows};

\tag{11.3}
\]

and

\[
\boxed{
\text{all unital associative }K\text{-algebras}
\subseteq
\text{quotients of associative shadows}.
}
\tag{11.4}

Moreover, the shadow map is generically many-to-one.

### Not established

The note does **not** prove that:

- every associative algebra is itself a category algebra;
- every classical algebra arises intrinsically from the fixed legacy FCOA-Z operation table;
- the universal realization is minimal or canonical;
- the target multiplication can be reconstructed without encoding it in the translation action or relation ideal;
- FCOA is historically prior to or foundational for ordinary category/semigroup representation theory.

## 12. Prior-art boundary

The broad realization statements deliberately rest on classical mathematics:

1. **Cayley representation for semigroups:** every semigroup embeds faithfully into a full transformation semigroup, for example by the regular action on \(S^1\).
2. **Wagner–Preston:** every inverse semigroup embeds into a symmetric inverse semigroup of partial bijections.
3. **Yoneda:** every small category embeds fully faithfully into a presheaf category; the construction in Section 4 is a concrete postcomposition version of this representation idea.
4. **Path/category algebras:** the path algebra of a quiver is the category algebra of its free category.
5. **Free associative presentations:** every unital associative algebra is a quotient of a free associative algebra on a generating set.

Accordingly, the universal coverage theorems are not offered as new representation theory.

The potentially distinctive FCOA problem begins only after adding the **source restrictions**:

- exact preservation of a pre-existing partial legacy operation;
- role-sensitive definedness;
- fixed coordinate geometry;
- typed terminal/output fibers;
- reflection constraints;
- bounded generator complexity;
- arithmetic-memory restrictions;
- minimal extension cost.

## 13. Existential coverage versus intrinsic emergence

The programme must now separate two questions.

### 13.1 Existential Shadow Coverage

Can a classical object \(A\) occur as some FCOA translation/operator shadow?

For semigroups, categories, category algebras, and quotient-associative algebras, the present note largely answers **yes**.

### 13.2 Intrinsic Shadow Realization

Can \(A\) arise from the **fixed audited FCOA-Z source** by a conservative extension satisfying the existing Line Completion Gate, without simply writing the multiplication table of \(A\) into new marker actions?

This remains the nontrivial research problem.

It should be formalized as a resource minimization problem.

## 14. Proposed Classicalization Cost

For a target classical object \(A\), define a candidate realization cost vector

\[
\operatorname{CCost}(A;F_Z)
=
(c_{sort},c_{cell},c_{gen},c_{depth},c_{coord},c_{memory}),
\tag{14.1}
\]

where the coordinates record, respectively:

1. number of genuinely new sorts;
2. number/density of newly opened primitive cells;
3. number of independent translation generators;
4. maximal primitive composition depth required by the construction;
5. number of new independently iterable coordinate directions;
6. arithmetic or equivalent structural memory introduced explicitly.

The lexicographic or Pareto-minimal realization problem is then:

\[
\boxed{
\text{minimize }\operatorname{CCost}(A;F_Z)
\text{ subject to conservative FCOA-Z realization of }A.
}
\tag{14.2}
\]

This is a research definition, not yet a theorem.
