## 3. Finite-fibre confinement in pure order

The key observation is independent of the graph construction.

### Lemma HD-1 — finite-fibre box confinement, dimension two

Let

\[
\psi(x,y,t)
\]

be an FO formula in \((\mathbb N,<)\), with finitely many fixed parameters allowed. Suppose that for every sufficiently large \(t\), the fibre

\[
F_t=\{(x,y):\psi(x,y,t)\}
\]

is finite.

Then there is a constant \(K\) such that for every sufficiently large \(t\),

\[
\boxed{
F_t\subseteq[0,t+K]^2.
}
\]

### Proof

Expand definitionally by the least element and successor. Quantifier elimination for the discrete order reduces \(\psi\) to a Boolean combination of atomic comparisons among finitely many bounded successor iterates of

\[
x,\ y,\ t
\]

and fixed parameter/constant terms.

Choose \(K\) larger than every successor offset occurring in this quantifier-free formula and larger than the finite boundary generated by the fixed parameters.

Assume, toward contradiction, that for arbitrarily large \(t\) there is

\[
(x,y)\in F_t
\]

with

\[
\max(x,y)>t+K.
\]

Consider the top coordinate cluster.

- If one coordinate exceeds the other by more than \(K\), increase that larger coordinate. All atomic equalities with the other coordinate, with \(t\), and with fixed constants remain false; all order comparisons remain unchanged. Hence the same quantifier-free type is realized by infinitely many tuples.
- If \(|x-y|\le K\), increase both coordinates simultaneously by the same amount. Their bounded relative offset is preserved, while both remain farther than \(K\) above \(t\) and all fixed constants. Again every atomic truth value is preserved for infinitely many shifts.

Thus one satisfying tuple outside the box produces infinitely many satisfying tuples in the same fibre \(F_t\), contradicting finiteness.

Therefore all sufficiently large finite fibres are confined to \([0,t+K]^2\). \(\square\)

### General dimension

The same argument works in fixed dimension \(d\): shift the maximal bounded-offset cluster of coordinates. Hence every finite definable fibre

\[
F_t\subseteq\mathbb N^d
\]

satisfies

\[
F_t\subseteq[0,t+K]^d
\]

for all large \(t\).

## 4. Rank bound for diagonal points

For a fixed diagonal point

\[
d_m=(m,m),
\]

\[
\operatorname{Pred}(m)
=
\{(x,y):(x,y)\prec d_m\}.

Because \(\prec\) has order type \(\omega\), every point has only finitely many predecessors. Thus \(\operatorname{Pred}(m)\) is finite.

The formula

There is a constant \(K\) such that for all sufficiently large \(m\),

\[
\operatorname{Pred}(m)
\subseteq

Therefore

\[
|\operatorname{Pred}(m)|

Hence the rank of the hub \(d_m\) satisfies

\[
\boxed{
\operatorname{rk}_\prec(d_m)
=O(m^2).
}
\]

This bound holds for **every** pure-order-definable \(\omega\)-order on the dimension-2 payload carrier, not only for the max-shell order.

## 5. Exact hub-density lower bound

### Theorem HD-2 — dimension-2 hub-density barrier

For every FO-definable order \(\prec\) of type \(\omega\) on \(\mathbb N^2\),

\[
\boxed{
H_\prec(N)=\Omega(\sqrt N).
}
\]

### Proof

From the rank bound there is a constant \(C>0\) such that for all sufficiently large \(m\),

\[
\operatorname{rk}_\prec(d_m)\le C(m+1)^2.
\]

The same bound, after enlarging \(C\), holds simultaneously for

\[
d_0,d_1,\ldots,d_m.
\]

Thus the first

\[
C(m+1)^2+1
\]

positions of \(\prec\) contain at least \(m+1\) diagonal points.

Given large \(N\), choose

\[
m=\left\lfloor c\sqrt N\right\rfloor
\]

with \(c>0\) small enough compared with \(C\). Then all \(d_0,\ldots,d_m\) occur before rank \(N\). Hence

\[
H_\prec(N)\ge c\sqrt N-O(1).
\]

Therefore

\[
H_\prec(N)=\Omega(\sqrt N).
\]

\(\square\)

No FO-definable reordering inside the same dimension-2 pure-order source can make the infinite nonlocal core logarithmic, iterated-logarithmic, or arbitrarily slowly unbounded.
