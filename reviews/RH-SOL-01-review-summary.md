# RH-SOL-01 review - programme takeaways

The review of RH-SOL-01 is treated as a roadmap for the next branches rather than as a request to rewrite the already published article.

Priority issues to answer in future work:

1. formalize the definition of the filled loop domain and boundary handling;
2. publish the full upstream pipeline from zeros to the incidence tensor;
3. repeat spectral analysis using actual zero ordinates;
4. add geometry-preserving, phase-randomized, and order-randomized null models;
5. compare the structured frequency dictionary with random dictionaries of equal size;
6. test shifted lattices and grid-resolution sensitivity;
7. separate sampling analogies from claims about mechanisms of zeta or RH.
