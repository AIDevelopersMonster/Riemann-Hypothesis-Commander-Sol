# Contributing / research discipline

1. Do not overwrite published results; create a new version or branch.
2. Record negative results.
3. Fix random seeds where meaningful and record them in experiment notes.
4. Separate exploratory tests from preregistered/confirmatory tests.
5. Do not claim novelty before a literature audit.
6. Do not label a line "new" until known `log n`, prime-power, nonlinear-mixing, sampling, and geometric null explanations have been tested.
7. Every article-specific result should link to the exact script and data version that generated it.
