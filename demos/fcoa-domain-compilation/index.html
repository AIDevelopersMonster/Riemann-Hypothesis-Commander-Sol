In G1 the path is an external relation and disappears when erased. In G2 the same directed path is encoded by definedness itself:

A_dir(x,y) ⇔ x,y ∈ G_N, x ≠ y, Def(x ⊗₁ y)

All compiled edges have the same terminal value Ω, so edge identity is not carried by edge-specific outputs.
