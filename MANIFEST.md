# Scaffold manifest

This ZIP is a repository scaffold for the RH-SOL research series.

Included:

- bilingual root README;
- article map RH-SOL-01 through RH-SOL-15;
- article and experiment templates;
- one directory per planned paper;
- reusable code/data/experiment/demo/review/release layout;
- citation metadata and MIT software license;
- Windows PowerShell repository bootstrap instructions;
- the published RH-SOL-01 DOI metadata.

No large datasets or publication binaries are embedded in this scaffold.
